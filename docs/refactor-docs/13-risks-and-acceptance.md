  未消化项、历轮审查遗留、D29、D28、过程红线 2.3-5；④ 与 07–12 无重复定义、

- **风险描述**：目标态嵌入浏览器采集依赖 Windows WebView2 的 profile 隔离、

  判定、事件顺序状态机）尚待自研，是 v2 分支试做时反复补"导航就绪归属、URL/
  事件顺序、ready 握手"的病根，若 M2 开工前未验证可能再次返工。
- **来源**：08:338（具体包选型待 M2 第 4 层）、08:522（开放问题：WebView2
  具体包选型与自动化原语自研 → M2 第 4 层；M2 前 feasibility spike）；
  11 D-08/D-09。
- **触发里程碑**：M2 开工前（feasibility spike）；M2 实现中（D-08/D-09 落地）。
- **验证方式**：M2 feasibility spike 六场景逐项执行——profile 隔离/导航顺序/
  可见登录/JS 原语/真清理/事件顺序；D-09 三标志位图状态机通过转移表全覆盖
  测试；fixture 全流程 + `compare_jw_bundles.dart` 逐字段对比 python-oracle。
- **关闭标准**：spike 报告六场景全部通过；D-08/D-09 按 11 冻结模板落地；
  M2 gate 全绿（analyze/test/build）且真实教务人工验收当场通过。

### R-03 学校页面/接口契约变化导致采集失败

- **风险描述**：五个来源的真实页面结构与反爬表现在旧房未系统验证，全部依赖
  固化选择器与端点常量；学校网站任何契约变化都可能使解析静默失真。红线要求
  契约变化时明确失败，不返回部分数据冒充完整结果。
- **来源**：02:329；AGENTS.md:239（网站契约变化时明确失败）。
- **触发里程碑**：M2（jw）/ M3（young）/ M4（icourse/campus）及此后每次
  发布前、每次学校网站结构变化发生时。
- **验证方式**：每来源保留契约变化探测回归样例（旧房真实故障样例优先，见
  R-08）；解析器 fail-closed 测试；M2–M4 当场真实人工验收 + M7 全链路
  真实验收。
- **关闭标准**：每来源解析失败路径均"明确失败、零部分数据"且测试锚定；
  M7 全链路真实验收通过；此后契约变化事件按同一纪律回归。

- **风险描述**：M2–M6 期间 Native 与 Python 通道并存，若通道切换/迟到结果
  防护（sourceGeneration、LeaseStamp、维护门）实现或配置有误，会出现同一
  来源两通道同时跑或双写。
- **来源**：09 CT-T-03（1044-1045）；08:490-492；AGENTS.md:338-349
  （并存方案/四铁律）。
- **触发里程碑**：M2 起至 M7（每通道启用时、每通道切换时）。
- **验证方式**：带事件序列断言的切换测试，严格覆盖 CT-T-03 顺序"旧作业
  终态释放 → sourceGeneration 递增 → 注册表换通道"，双向各一遍
  （Native→Python、Python→Native）+ 取消失败与旧作业迟到场景；generation
  递增/迟到拒绝组合级测试；一源一通道配置矩阵测试；真实切换人工验收
  （Native↔Python）。
- **关闭标准**：事件序列全部满足 CT-T-03、测试全绿且无通道双跑记录；
  M7 Python 通道与 Bridge 全部删除。

### R-16 旧房（main + Python 五链路 + CLI）可运行、可回退保持

- **风险描述**：重构期间若误删/误改旧房 service、测试或真实故障回归样例，
  或 main 冻结纪律被破坏，将失去可回退基线。
- **来源**：07:77（过程红线 2.3-3）；AGENTS.md:338-349（并存方案/四铁律）。
- **触发里程碑**：M0–M7 每个里程碑。
- **验证方式**：main 冻结只进设计文档与致命修复（git 检查）；每个 M0–M7

  指定验证结果、旧安装包与 v7 备份校验值、回退通道可用性检查；M1/M5/M7

- **关闭标准**：M0–M7 里程碑记录齐全、可审计；M7 前最后一次恢复演练成功；

### R-17 真实验收的环境依赖（校园网/iWAN/学校账号/时间窗口）

- **风险描述**：红线 2.3-1 要求学校页面里程碑真实人工验收当场做；验收依赖
  校园网或 iWAN、真实学校账号、学校系统可用性等外部条件，存在窗口错位风险

- **来源**：07:75（过程红线 2.3-1）；01:279-280；02:329。
- **触发里程碑**：M2/M3/M4（每来源首次真实验收）、M6（真实 Key）、M7（全链路）。
- **验证方式**：每里程碑验收清单当场执行并记录 `完成：`；无法当场完成的

- **关闭标准**：各里程碑真实验收项全部当场通过；M7 全链路真实验收通过。

### R-18 自动同步真开关（D31）

- **关闭标准**：M5 验收通过、文案与行为一致；或用户明确决定不提供真开关
