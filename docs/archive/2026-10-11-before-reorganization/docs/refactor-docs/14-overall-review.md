### 1. 审查方法与执行

- **A：机械一致性**。主代理核对当前决定、契约、风险登记、引用、旧结论残留和 Git 基线。
- **B：场景走查**。4 个子代理按 07→08→09→10→11→12→13 逐层追踪 13 个场景，记录输入、责任方、状态转换、提交点、失败恢复及验收去向。

若真实验证迫使改变学校只读、认证资产不透明、完整产品范围或既有数据保留承诺，提交具体证据和可选方案请用户决定。迁移后已有新写入而回退可能丢失数据时，也必须届时由用户选择保留/导出/放弃范围。本轮不默认批准此类取舍。
