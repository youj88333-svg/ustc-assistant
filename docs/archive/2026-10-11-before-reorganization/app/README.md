- **取消与清理**：“取消本次二课作业”停止未完成读取，保存成功的结果继续保留；窗口关闭未完成时使用“重试二课收口”。“清除二课登录资料”只删除本应用二课分区，保留二课日程，以及教务日程、密码、学期目录和登录资料。
