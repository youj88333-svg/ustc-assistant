| 档案 | 保存内容 | 使用方式 |
|---|---|---|

快照中的“当前”“待验”“通过”和旧分支、路径、接口均指写入时状态；其规范效力由现行设计与明确用户批准决定。旧失败、用户验收和未观察项保留原文，不用历史关闭结论证明新分支交付。

历史设计中的源码位置与外部引用可能已失效，不作为现行链接检查的对象。整理后实际使用的链接和标题锚点在档案之外维护。
