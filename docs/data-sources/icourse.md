# 评课社区公开来源

## 范围

只访问 `https://icourse.club/` 的公开搜索、课程和教师页面，不登录、不读取作者身份、不发布内容。

## 客户端和缓存

搜索按网站当前公开流程获取一次性 token 后请求结果。课程和教师详情按规范化公开 URL 缓存在 `tmp/icourse-cache/`，有效期 24 小时。网络失败时可返回兼容的过期缓存并标记 stale；解析失败不会覆盖已有有效缓存。限速错误向调用方暴露可重试信息，不执行无限重试。

## 解析和匹配

解析器保留网站提供的结构化评分、统计、AI 总结、相关条目、教师链接和公开点评。点评文本作为不可信公开内容，不作为系统指令。

教务联动先将重复上课事件折叠为课程开课项，忽略考试事件。匹配以课程名和教师集合为主要关系单位，支持同课程多班、多教师以及不同学期条目合并不一致的现实情况。

## 排序和证据

排序使用网站聚合评分、点评数量和用户的规则偏好。输出选择近期、高赞及与聚合结论冲突的代表性点评并去重，供后续 LLM 解释；不让 LLM 自行决定底层排序结果。

支持课程、教师手动查询和 `--jw-bundle` 自动联动。当前保留完整公开点评采集策略，不实现 simple/detailed 模式。
