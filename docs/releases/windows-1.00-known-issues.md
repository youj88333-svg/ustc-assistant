# Windows 1.00 已知问题与验证范围

适用于2026-10-25刷新的Windows x64私有包（1.00 / 1.0.0+1，源码441a68b，schema20）。版本认可与每项功能的实际证明分开；当前没有公开发布，以下事项继续保留，不把手机、MuMu或合成测试的结论当作Windows逐项真人验收。

| 项目 | 当前事实与使用建议 |
|---|---|
| 本地中文语音 | 真实反馈曾出现只识别“I.”或未识别出语言；麦克风通道与上下文的确定缺陷已修过，但没有取得真实设备识别质量的新确认。自动链路使用合成音频，不能替代实际录音质量。语音失败时仍可文字输入，不把关闭M5解释为识别已验收 |
| Agent与模型 | 真实模型的语气、图片理解、长对话和工具选择依赖所选模型及服务；离线测试不证明每次回答正确。修改以应用提交回执为准；仅建议模式保留，学校操作只读。共享Agent来源拒绝解释已有工程修复，最终真实稳定性补验仍保留，不因模型说已同步就视为成功 |
| 可选DeepSeek官方服务 | 已有最小真实文本/流式/合成工具往返证据；完整Windows业务、图片、速度及账单没有据此全部验证。需单独Key和联网同意，独立计费；学校配置保留，不会自动切换或回退 |
| 教务考试 | 空考试及接口链路已验证；真实非空考试由用户同意后补验 |
| 来源调整 | 完整学期/日期范围内不再返回的旧场次会退出有效日程，范围外历史保留；真实教务调休与二课撤回案例尚无新实证。二课只依据学校个人日历的活动关联记录，不宣称独立核验报名/取消状态 |
| 每日二课 | 默认关闭；启用后06:00后运行中的应用可见空闲时同步，不消耗模型额度。学校挑战、无已保存密码或网络失败会停止/退避，退出后不运行。长期真实触发和各种网络切换仍待使用反馈 |
| Windows提醒 | 已有隔离身份下退出后系统记录、取消和冷启动证据；实际弹窗可见性、用户真实点击、系统重启/睡眠/勿扰等场景未全部实测。系统设置关闭或调度失败应显示状态，登记成功不等于一定看见提醒 |
| 校园公开信息 | 财务在线关键词搜索/FAQ不可用，固定栏目与精选知识资料仍可查询。材料是否现行及适用于个人情况不自动确认；校园IP限制的真实自动直连回退未补验 |
| 私有包运行环境 | 当前开发机普通Release已构建检查，沿用已验证的441a68b二进制；全新Windows机器、杀毒信誉提示、安装器和数字签名尚未验证/提供。完整解压、WebView2与必要运行库仍是前提；本轮只打包，不打开正式资料或自动启动应用 |
| 升级与旧版回退 | 本次增量升级到schema20并保留原资料、密码和通知身份。旧schema18程序不能直接读取升级后的库，旧包留存不代表能无损回退；当前没有业务备份/恢复入口，不通过清数据或覆盖旧程序绕过错误 |
| 设备与资料 | 本包仅Windows x64。账号/模型Key按当前Windows用户保护，未实现手机密文迁移、桌面手机同步或可导出的业务备份；卸载/删除资料前应清楚影响。鸿蒙后台返回修复反馈不等同Windows所有生命周期场景均已验收 |
