# Android / APK鸿蒙私有QA已知问题和保留项

适用：2026-10-25私有交付QA2024（ARM64）/QA4024（x86_64），源码441a68b，schema20。当前沿用QA身份，尚未切换独立签名的正式Release；安装包可在已验证环境继续使用，不代表所有Android或鸿蒙型号全面验证。

## 设备与使用

- 用户MatePad 11.5″S / HarmonyOS 4.2.0直接安装APK，日常使用总体获认可；原“切后台再返回后目录被另一实例占用”已由用户复验、未再出现。该结论只覆盖已报告设备和操作，不推定其他型号、版本或兼容容器。
- MuMu已有真实学校自动认证、空/非空二课同步、Agent审批/撤销、竖屏、评课、图片及其他旅程证据；官方模拟器另有隔离的合成检查。ARM64普通Android手机、多厂商ROM及原生鸿蒙HAP没有本轮完整实机证据；本包不支持原生鸿蒙HAP安装场景。
- 应用安装下限API24；学校同步依赖API28+普通系统WebView和实际运行能力。打开网页或安装成功不能单独证明采集可用。学校验证码、额外授权和服务变更仍可能需要用户处理。

## 尚未单独确认的实际行为

- 真实短中文麦克风仍需目标机专项确认；历史“I.”、麦克风不可用及未识别语言的问题没有新的逐项真人关闭记录。合成语音识别通过不能代替真实录音。
- 次日北京时间06:00后的首次前台自动准入、长期挑战退避，以及真机精确/锁屏/省电/重启/强停等通知策略尚未逐项复验。晨报和每日二课是用户启用后的前台作业，应用退出后不运行学校采集；系统通知另由OS调度，是否及时可见还受许可和设备策略影响。
- QA4022来源同步被拒绝后，模型对拒绝原因的最终真实解释复测曾被用户中断。应用层同轮拒绝守卫与工程测试已落实，不能据此宣称模型每次解释均已稳定正确；已拒绝的当前作业不得当作已同步。
- 教务真实非空考试、学校实际调休/撤回、二课真实取消等样本仍有保留项。二课只导入个人日历中的活动关联记录，不独立证明本人报名成功或取消；没有返回不等于已验证报名状态。
- 新引导、整体UI及来源业务明细的全部逐项体验没有由本轮总体反馈补造为通过。模型回复、思考字段、速度、图片能力随提供方和所选模型变化；官方服务只做过最小真实能力核验，没有用其追加全量业务测试。

## 资料、升级与恢复

- 本版保持QA包名及证书，正常覆盖升级保留原QA资料。卸载、清数据、切换正式身份或直接降级均不是无损恢复方法；schema20不能由旧版直接读取。本期没有业务备份、云同步或Windows资料迁移功能。
- 应用资料不作为可直接搬迁的备份；学校密码、模型Key、浏览器会话不能跨设备复制使用。设备密钥失效时需在应用重新提供凭据，既有日程不应因此被删除。
- 报错先导出安全日志，再说明设备版本和触发步骤。日志有条数/时间范围，选择被截断会明确提示，不代表全部历史；日志不包含用于恢复日程的业务数据库。不要把账号密码、模型Key、学校原始响应或认证文件交给开发者。
- 包内本地语音模型约239MB，导致APK约282/294MB；私有QA的体积、启动和性能不等同于以后正式Release。正式签名、商店发布及更多设备适配留待下一轮。
