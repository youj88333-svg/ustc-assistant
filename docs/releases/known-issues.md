# 1.0.0公开版的已知问题与证据范围

本页供Windows/Android公开版共用；不把此前阶段关闭或测试版总体反馈当作所有机型和实际服务的逐项通过。具体证据继续查[状态页](../status.md)、[Windows原记录](windows-1.00-known-issues.md)、[Android原记录](android-private-1.00-known-issues.md)及[设备矩阵](../milestones/android-apk/device-matrix.md)。

- 真实中文麦克风听写曾出现只返回“I.”或未识别语言；不能承诺所有设备/录音环境已解决。录音先转成可编辑文本，不自动发送。
- 学校验证码、额外授权、会话过期、校外网络和接口变化仍可能暂停或使采集失败。二课只同步个人日历中的活动关联记录，不能独立证明报名成功/取消状态。
- 非空考试、实际课程调休/来源撤回内容对应、部分模型解释质量等未取得完整新实证。同步/模型回答不替代学校正式通知。
- 每日06:00触发、真实设备省电/后台/重启和厂商通知策略仍需对应设备验证。系统“强制停止”与普通退出不是同一场景；通知登记成功不等于已实际送达。
- Android包仅覆盖ARM64和x86_64；鸿蒙仅适用于能够安装APK的版本，不能据此宣称支持原生鸿蒙。正式身份与此前测试版分开存储，不自动迁移资料。
- Windows依赖WebView2 Runtime及相应运行库；本版未代码签名，新机器兼容性仍按实际验证披露。已有资料格式升级后不能直接由旧版降级读取。
- 模型响应速度与能力依赖所选服务；用户自行提供并管理Key，官方API可能产生费用。私人资料是否发送依当前许可和工具实际调用而定。

反馈时提供版本、设备/系统、时间、步骤和应用导出的安全日志即可；不上传账号密码、API Key、私钥、数据库、浏览器资料或学校原始响应。潜在漏洞按[安全报告说明](../../SECURITY.md)私下处理。
