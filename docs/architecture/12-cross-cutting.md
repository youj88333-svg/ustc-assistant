2026-10-09 按 [07](07-constitution.md)及 [09](09-contracts.md)修订；语义权威在下表归属模块，其他模块只负责能力、编排或消费。旧参数和通过记录不自动成为新基线。

### 恢复、隐私与可观测性

启动先取得规范化目录排他所有权，再按 [10](10-runtime.md)恢复持久 reset、必要迁移及分区许可状态，完成必要恢复后开放来源、Agent 和业务写。C3 提交成功而 P 认领失败保持已提交事实，按具体许可重试，不重做业务事务；取消不能跳过必要认领或 drain。P 真清理失败保持待办，不能记清理成功。正式分区未知身份的非破坏性失败，与未提交 initial/recovery 候选回收分别处理；既有账号没有可用分区保留业务并提供受控重认证恢复路径。

公开进度不承载内部业务载荷、实际账号、证据 URL 或认证状态；内部规范化交接只供已登记消费者，进入 UI、模型、日志前分别构建安全投影。错误使用固定码和文案，避免带入原始响应或异常堆栈中的秘密。对账只记录状态、数量、必要版本及耗时，身份原值不作为调试信息。

持久诊断先取得应用目录所有权，固定子目录/文件经平台路径校验，导出重新解码并重建白名单投影；每条事件保留产生时的构建、库、工具及提示词版本。启动无法安全访问目录时只导出本次内存错误，明确不含既有日志。保留覆盖、坏行、丢弃和截断分别声明；诊断不是私人业务重播数据，复现使用对应版本、轨迹和合成契约。导出、清理、关闭串行排空后再释放目录，清诊断不清业务/历史/凭据；清历史或业务不自动清诊断，整应用重置按已确认范围清除。

语音听写复用相同的用户主权与最少出站边界：只有用户主动点击才申请麦克风，模型首次需要时才加载；本机固定模型在 CPU isolate 识别。录音固定使用 `record 7.1.2`、推理固定使用 `sherpa_onnx 1.13.8`；PCM 仅在任务内存中存在并受 30 秒/960000 字节上限约束，不落文件、不自动上传或下载。不启用持续监听、TTS 或 Agent 录音工具。取消及上下文失效先撤销转写交付，再排空录音/识别；应用进入 inactive、hidden、paused 或 detached 时也取消，不在后台继续录音。模型缺失或识别失败保留普通键盘输入。日志仅允许固定阶段/失败码、计数和耗时，禁止音频、转写文本及设备名。约 228 MiB 的 SenseVoice 固定权重不纳入 Git；SDK 与模型权重许可单独声明，开发准备/校验和随包 NOTICE 见 [M5.8 记录](../milestones/m5/records/08-local-speech-input.md)及[随包 NOTICE](../../app/resources/speech/NOTICE.txt)。

原始调试文件仅在用户显式要求时落私有目录，不进入 Git、日志或发布包；provisional debug 与会话分区分别登记和清理，不能用 debug 调和代替会话回收。跨数据库与文件操作采用持久意图和幂等恢复，原件、旧工程或外部目录不作为清理目标。

迁移回退方案区分发布前失败与发布后已经写入新业务的回退。保留原件并不等于能无损带回新写入；目标映射确认时必须说明可保留的新资产范围、潜在损失及恢复验证，发生回退时由用户依据实际影响选择，不自动覆盖或丢弃新资产。凭据保护与跨设备可解密性单独验证，业务迁移不携带浏览器认证资产。

物理删除需确认浏览器占用已释放；Windows 的 UDF 删除时序以平台能力验证为准。[Microsoft UDF 管理说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/user-data-folder) 移动端尚未验证等价能力，不以接口同名记为通过；权限、提醒发布、附件限额和缓存参数在对应设计时确认。

教务凭据实现续记（2026-10-10）：P 的 `dpapi-current-user-v1` 整体保护用户主动提供的登录账号和密码，使用稳定 owner/账号用途绑定的可选 entropy，不使用 LocalMachine 或明文回退。C3 是密文的唯一持久事实源；现有业务账号字段仍用于身份核验，不宣称整个数据库加密。一次租约仅取一次，取消、新作业、维护、失败及收口撤销未消费租约；可变临时字节尽力零化，Dart 不可变字符串及运行时内部副本不作完全抹除承诺。错误、进度和审计不包含秘密、密文或用途值；界面不回填已保存密码。实际当前 Windows 用户的 roundtrip、错误用途和篡改拒绝已用合成秘密验证，跨设备迁移不作保证。正式 JW 自动认证已获 [M1 用户验收](../milestones/m1/acceptance.md)，其余平台仍分别验证；具体来源行为见 [JW 参考](../reference/sources/jw.md)。

学校共享凭据续记（2026-10-11）：用户确认 JW/Young 是同一账号并授权复用认证逻辑。C3 保留一份学校账号/密码密文事实与既有 DPAPI 用途，两来源分别申请受原戳约束的单次租约；不迁移、复制或读取浏览器认证资产。来源独立分区、verifier、认领许可及全局互斥保持。二课成功查询/导入可与共享新密文同事务提交；失败、取消、保护/SQL 错误不替换旧密码。删除保存密码明确影响两来源，清 Young 登录资料不删共享密码或 JW 资产。跨来源界面更新只广播提交后的存在布尔值；实际账号、秘密、密文、用途和业务载荷不进入事件。共享认证分别获 [M1](../milestones/m1/acceptance.md)与 [M2](../milestones/m2/acceptance.md) 的用户验收，不能以某一来源通过推定其他来源通过；具体行为见 [Young 参考](../reference/sources/young.md)。
