# JW 教务来源契约

本文是本分支 JW 教务当前来源字段、范围和规范化语义的唯一详细参考。通用身份、作业、分区、事务与安全规则见 [09 关键契约](../../architecture/09-contracts.md)；本分支 M1 的真人验收和关闭状态见 [M1 验收记录](../../milestones/m1/acceptance.md)。

## 能力与当前状态

M1 已正式验收关闭，范围是 JW 可信身份、只读课表/考试读取、事务导入、凭据与学期选择、作业恢复及本地展示。关闭决定没有把未观察的内容改为已通过；真实非空考试仍待后补验证。关闭范围和逐项验收以 M1 验收记录为准。

M4.2 补齐原来遗漏的地点、教师等日程事实，采用下文 v2 规范化契约；工程与真实字段核对分开，修复证据见 [教务信息完整性记录](../../milestones/m4/records/04-jw-academic-details.md)。

本契约覆盖：

- 读取本次明确选择的单个学期课表，并将有效课表行导入本地日程。
- 读取考试页面中实际观察到的考试行；考试没有独立学期归属字段。
- 本地保存学校学期目录供用户选择。目录项不是身份依据，也不授予读取或导入许可。

页面可达、历史候选探针或合成响应本身都不构成身份判定、封存或导入许可。正式作业仍须满足通用 C1/C2/C3 契约。

## 固定入口与只读操作

初始入口为 `https://jw.ustc.edu.cn/`。当前允许来源 origin 固定为：

- `https://jw.ustc.edu.cn`
- `https://passport.ustc.edu.cn`
- `https://id.ustc.edu.cn`
- `https://analytics.ustc.edu.cn`

产品只接受已登记的页面类型和本地学期选择，不接收任意页面 URL。固定页面入口为 `/for-std/course-table` 与 `/for-std/exam-arrange`，由学校解析自身页面详情路由。

当前数据读取使用固定的校内只读请求：

- 身份页面：`/for-std/student-info/info/{dataId}`。
- 学期及课表页面：`/for-std/course-table/info/{dataId}`。
- 课表索引：`GET /for-std/course-table/get-data`，参数固定包含 `bizTypeId=2` 和本次已验证的 `semesterId`。
- 课表详情：`POST /for-std/course-table/datum`，请求只包含索引中通过校验的课程标识。
- 考试页面：`/for-std/exam-arrange/info/{dataId}`。

这些请求用于读取，不执行学校业务写入。索引请求固定还带当前页面上下文 `dataId`。页面可自行产生的其它常规请求仍按通用来源与浏览器规则处理；本表只定义产品主动执行的读取。`dataId` 是当前学校页面路由上下文，不是学生身份、课程稳定键或本地账号标识。

学期目录的 `id` 是学校不透明正整数，`name` 是本地显示标签，默认标志只用于选择辅助。目录限制为 1–256 个唯一 ID；学期 ID 必须来自本次目录并在本次读取中再次被接受。首次默认项按北京时间月份匹配唯一标签：2–6 月当年春、7 月当年夏、8–12 月当年秋、1 月上一年秋，仅匹配实际目录 ID。后续默认上次成功项，用户可在开始前改选。缺失、歧义或已消失的选项要求明确选择，不推算学校 ID 或静默换期。

## 身份与响应关联

正式采集先后读取同一当前身份页面，要求恰好一项有效身份候选且前后稳定；同时要求当前路线与已登记 JW 页面绑定、所选学期被页面接受。当前作业、浏览器会话、主文档和读取操作必须保持关联，检查失败时不封存数据。

身份值只在受控作业链内与 C3 已有预期账号比对，不向 UI、普通进度、日志或审计输出实际账号。页面自报信息、URL、存储、Cookie/Token、已认领分区存在或页面可达均不能单独替代该比对。C3 只绑定一个本地账号；JW 与 Young 分别核验同一预期账号，浏览器分区、核验依据和来源许可独立。经批准共享的是用户提供并加密保存的学校密码事实，不是登录会话或身份核验结果。

身份前后不一致、路线未绑定、身份缺失、学期未知、上下文过期或响应关联失败，均拒绝整个本次快照，不把部分数据交给导入层。错误诊断只使用闭合原因码和有界计数，不携带原始页面、请求、账号或业务值。

## 字段、时间与稳定键

当前采集使用 `jw-course-exam-v2`，载荷只接受闭合的 `version`、`semesterId`、`courses`、`exams` 结构；version 必须匹配当前契约，未知字段、缺少字段或类型不符均拒绝。旧 v1 载荷不能声称已完成新采集。课程行字段为：

| 字段 | 语义 |
|---|---|
| `lessonId`、`groupId` | 学校课程与分组的不透明正整数标识 |
| `date` | 明确的公历日期 `YYYY-MM-DD` |
| `startMinute`、`endMinute` | 当日分钟数，范围 0–1439，且结束严格晚于开始 |
| `title` | 本地课程标题 |
| `academicDetails` | 闭合 `jw-academic-details-v1` 规范化学校事实，当前 19 项字段 |

考试行字段为 `courseCode`、`examType`、`date`、`startMinute`、`endMinute`、`title`、`academicDetails`。考试时间同样要求明确日期和当日分钟范围；考试不从课程、学期标签或周次推导日期。

学术详情只保留已登记来源字段，不保存原始响应或任意扩展：

| 来源事实 | 固定映射与语义 |
|---|---|
| 地点 | 每次上课行的 `room.nameZh`/`room.code`、`room.building.nameZh`、`room.building.campus.nameZh`、`customPlace` 与可空 `room.virtual`；分别保留校区、楼宇、教室/代码、补充地点和虚拟标志。显示以教室名称优先，缺失则取代码，再取补充地点，后接已知楼宇、校区；不解析代号推算楼层/校区，不因部分结构而丢补充地点。排序只改展示，存储事实/版本不变 |
| 教师 | 每次上课行 `personName`，不保存 teacherId/personId。姓名集合去重并按确定顺序保存，可多名；最多 64 名，每名 100 字符 |
| 课程 | `lesson.code` 和 `courseTypeName` 形成课程号/类别；lesson/group 标识与行所属必须一致。课表学期标签来自本次服务端目录中已接受 ID 的 name，不按日期造标签 |
| 教学安排 | 行 `weekIndex`、`weekday`、`periods`、`exerciseClass`，缺失为未知，不按钟点反推；已提供星期须与明确日期一致。可空整数/布尔使用已登记类型/界限，不接受任意对象 |
| 考试 | 固定八列表的考场、教学楼、校区和考试说明，另保留当前 courseCode/examType。考试没有已核验学期/教师字段，这些项为空，不从课程关联推断 |

上述详情结构包括固定 version；各普通文本最多 200 字符，考试说明 4000 字符，编码最多 24576 字符，出现非空畸形类型、越界或禁止控制字符拒绝整批，不静默删掉重要字段。实际学校字段确实缺失时可保存空/未知。旧日程的空详情对象引用（库内 NULL）表示尚未采集，界面须提示重新同步；新详情内缺字段只表达本次来源未提供，不能声称学校全局没有此信息。当前新字段的真实本人核对与历史 M1 关闭、非空考试待补验分开记录。

日期与分钟解释为北京时间（UTC+8），存储为对应 UTC 时刻。拒绝无效日期、结束不晚于开始、跨日推断、缺失时间或不受支持的时间形状；不按运行机器时区转换。

课程自然键由选定学期、`lessonId`、`groupId`、日期和开始分钟组成；考试自然键由 `courseCode`、`examType`、日期和开始分钟组成。键经规范化后作为稳定外部身份，不使用数组位置、页面 `dataId` 或标题单独构造身份。

## 完整性、重复项与失败

当前课程作业范围是用户选定的一个学期。索引和详情须完整对应，课程数、日期数、时间数及关联计数须一致；出现分页迹象或无法证明完整性时拒绝整个快照。课程与考试合计最多 10000 行，限制在重复项合并前执行。

考试只代表本次页面实际返回且逐行验证的行。空考试结果不证明整个学期或历史范围完整；当前仍没有真实非空考试样本，按 M1 验收记录继续列为待补验。

规范化先验证每一行和全部必需字段，再按自然键合并规范化事实一致的重复课程或考试行。课程行仅教师姓名集合不同允许合并并取并集，仍只有一条日程；同键的地点、名称、时间、学期或其它规范化事实不同则拒绝整个快照，考试内容差异也拒绝。逐类满足来源行数 = 唯一事件数 + 合并数；实际导入数量以唯一事件计，内容指纹涵盖新详情，不受教师排序或重复行次数/排列影响。安全计数分别表达来源行、唯一事件和合并项，不携姓名/地点，不得把合并数量当成导入事件数量。

传输失败、响应结构错误、字段冲突、部分索引/详情、重复键内容冲突、身份或文档关联失效，都使本次作业失败；不以空数组、已完成的较早步骤或部分页面降级为成功，也不改变已有导入事实。

## 本地提交与保留语义

C3 仅消费完整、身份匹配且来源契约版本有效的封存产物。在一个本地事务中写入本次唯一事件集、范围观察状态、适用课程的 `source_retired`、导入回执、审计、分区认领许可和成功学期；已验证目录以及本次新凭据仅随成功事务提交。只有同一完整选定学期内不再返回的旧课程才标为 `source_retired=true`；考试没有可靠完整覆盖，空考试集不推断失效。同步其它学期仅更新对应观察状态，不修改该课程的失效位；原本正常的旧学期课程继续在原日期显示，已失效课程也不会因此复活。

同一完整学期再次返回相同课程自然键时，将 `source_retired` 恢复为 `false`，保留本地事件 ID 和全部用户覆盖（包括备注、隐藏、出勤/听讲与提醒设置）。日期或开始时间变化会形成新自然键，不将旧事件备注或覆盖搬给新键。导入失败、取消或回滚不产生部分停用；重放同一操作不得重复导入或生成重复回执。

schema 7→8 为 JW 事件增加有界规范化详情，旧行仍保留并标为未采集；合法早期链同样升级，失败整笔回滚，不清业务或会话。重新同步所选学期按原自然键补齐地点/教师等事实，更新版本而不新建重复日程；其它学期不会自动补齐，需用户在同步前明确选期。备注、隐藏、出勤/听讲与已保存判断、个人事件/例外、凭据/目录与知识继续保留。

完整课表仅限定本次选定学期。考试当前没有已验证的学期范围，不能用空集将其它考试标成已缺失。失败或取消先于事务提交时不产生部分业务导入；事务提交后的收口按通用提交与恢复规则处理。

JW 可使用同一加密保存的学校密码事实发起认证，但仍以 JW 自身的当前服务端身份、作业票据、只读响应和独立分区完成核验。共享密码不意味着共享 Cookie、页面会话、已认领许可或 Young 身份。

## 明确保留的未知项

- 真实非空考试行及相应展示/重复采集行为仍待后补验证；M1 已关闭不代表此项真实通过。
- 地点、教师等信息完整性修复随 [M4.2 最终验收](../../milestones/m4/acceptance.md)关闭；不由整体使用判断补造额外响应形状、逐字段样本分布或正式数据计数，静态映射与合成 Windows 仍与人工证据分开。
- 不从空考试页面推定全学期、历史考试或撤销状态的完整覆盖。
- 旧分支接口、旧 Schema、历史探针结果及旧验收记录不覆盖本契约的当前字段与状态。
