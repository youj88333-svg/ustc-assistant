# 评课社区公开查询

状态：2026-10-11 匿名公开网页研究；尚未完成产品受控 HTTP 契约与真实验收。依据 [09 K-01/K-03/K-04](../../architecture/09-contracts.md)、[07](../../architecture/07-constitution.md)的最少出站/首次授权及 [M3 范围](../../milestones/m3/plan.md)，不申请学校凭据或评课账号。

## 已观察的页面与请求

固定站点为 https://icourse.club。课程列表 /course/ 的原生表单 GET /search/、字段 q，提示搜索课程/老师；分类和排序由站点控件提供。主代理在内置浏览器验证“数学分析”查询、结果第二页和一门课程的学期过滤；教师独立查询、所有空态及产品 HTTP 路线仍待验证，不承诺课程代码检索。

已观察分类参数 course_type 的 liberal/physical/english/mooc/dual-degree/graduate，列表排序 sort_by 有 rating/popular。详情示例为 [数学分析 B1（程艺）](https://icourse.club/course/13486/)；详情排序控件包含 upvote/pubtime_desc/pubtime/score_desc/score，学期控件给出实际路由和筛选数量。仅支持正式契约验证后的固定选项，不允许调用方拼接任意参数。

课程身份按站点课程 ID 及对应教师/课程信息验证；同名不同教师、不同层次不能按名称合并。详情可能涵盖多个开课学期，当前筛选结果与课程所有历史评价不同。分页/是否还有下一页以真实页面控件证明，不根据估计数量生成未经许可页面。

## 字段与阅读范围

| 观察 | 契约影响 |
|---|---|
| 例页显示评分 9.9、48 人评分和 50 条点评 | 评分人数与点评数独立，不用 DOM 节点数或一个字段代替另一字段；数值按真实标签解析 |
| 筛选 2025 秋后标 9 条点评，但外围点评相关容器计数不同 | 使用可见有效点评/删除状态和站点字段，不能以粗略容器数量证明完整性 |
| 未评分占位文字不是数字 | 显示未评分，不补零或最高分 |
| 同页有已删除点评提示、回复和作者链接 | 点评、回复、删除标记分别处理；不递归抓取作者档案或把回复当点评 |
| 详情 HTML 含大量隐藏培养方案弹窗与站点生成的 AI 总结 | 只提取课程/教师/学期/评分与公开点评目标区；隐藏弹窗、培养方案、排名、AI 总结不进入本期结果 |
| 某附件明示登录后下载 | 该附件内容与下载入口从可用材料中排除；本期不接入账号或下载点评附件 |

内部结果只交付来源材料，不生成汇总观点或自动评价课程；携带来源、查询时间、筛选学期与覆盖，供未来 Agent 安全投影和引用，避免将旧学期/单个点评表示成当前共同意见。课程结果和必要正文只保留有界会话缓存，不建立评论知识库或持久检索历史；M3 临时入口只用于契约核对，不作为独立产品功能。

## 出站与未验证项

首次联网前告知该第三方站点并取得授权；只发送必要课程/教师关键词，不送学号、学校密码、整份课表或用户日程。来源链接和点评文本是不可信数据，不能提供新目标、脚本或权限。不得执行点赞、收藏、发布、修改等业务动作。

内置浏览器匿名查询可用；一次性直接 HTTP 在本机现有代理下曾出现 TLS EOF，尚未定位，不能据此认定学校/评课契约失败，也不能把浏览器探索当作产品替代通道。M3.1 需验证实际受控 HTTP、正确 TLS/代理、必要表单参数、字符编码、教师查询、分页、合法空态及站点错误/限流形状。取消/新查询后的迟到结果拒绝、规范化字段和资源上限按通用契约实现。

实际研究与原生验证边界见 [M3 研究记录](../../milestones/m3/records/02-public-materials.md)。本参考中的课程编号是公开站点示例，不是用户账号、个人选课或评分数据。
