# 评课社区公开查询

状态：2026-10-12，内部 public-query-v1 已装配，正式 Dart 匿名 HTTP 已作有限公开契约复验；临时界面仅为可选核对辅助，M3 阶段关闭待用户确认。依据 [09 K-01/K-03/K-04](../../architecture/09-contracts.md)、[07](../../architecture/07-constitution.md)的最少出站/首次授权及 [M3 范围](../../milestones/m3/plan.md)，不申请学校凭据或评课账号。

## 已观察的页面与请求

固定站点为 https://icourse.club。内部课程/教师查询使用 GET /search/，字段 q 和固定 noredirect=True；后者防止没有课程时转入点评搜索。课程与教师关键词、真实结果第二页、课程详情和合法空态分别验证，不承诺课程代码、点评全文或任意全站搜索。分页 page 只取真实下一页控件，并复验原关键词；空 term 可以规范化，不能改变查询意图。

详情示例为 [数学分析 B1（程艺）](https://icourse.club/course/13486/)；内部排序枚举对应 upvote/pubtime_desc/pubtime/score_desc/score。学期目录只接受同课程路径、数字 term 及实际“年份＋春夏秋冬”标签，末尾筛选计数单独去除；只允许剥离精确 #review-anchor 片段。排序/评分控件也可能携带当前 term，不能因此成为学期选项。筛选前重新读取目录，调用方不能自行拼接新学期或 URL。站点其他分类/列表排序只作为研究线索，未成为本期端口。

课程身份按站点课程 ID 及对应教师/课程信息验证；同名不同教师、不同层次不能按名称合并。详情可能涵盖多个开课学期，当前筛选结果与课程所有历史评价不同。分页/是否还有下一页以真实页面控件证明，不根据估计数量生成未经许可页面。

## 字段与阅读范围

| 观察 | 契约影响 |
|---|---|
| 评分、评分人数和点评数有各自真实标签，随页面/筛选改变 | 三者独立，不用 DOM 节点数或一个字段代替另一字段；数值按真实标签解析 |
| 筛选 2025 秋后标 9 条点评，但外围点评相关容器计数不同 | 使用可见有效点评/删除状态和站点字段，不能以粗略容器数量证明完整性 |
| 未评分占位文字不是数字 | 显示未评分，不补零或最高分 |
| 同页有已删除点评提示、回复和作者链接 | 点评、回复、删除标记分别处理；不递归抓取作者档案或把回复当点评 |
| 详情 HTML 含大量隐藏培养方案弹窗与站点生成的 AI 总结 | 只提取课程/教师/学期/评分与公开点评目标区；隐藏弹窗、培养方案、排名、AI 总结不进入本期结果 |
| 某附件明示登录后下载 | 该附件内容与下载入口从可用材料中排除；本期不接入账号或下载点评附件 |

内部结果只交付来源材料，不生成汇总观点或自动评价课程；携带来源、查询时间、筛选学期与覆盖，供未来 Agent 安全投影和引用，避免将旧学期/单个点评表示成当前共同意见。课程结果和必要正文只保留有界会话缓存，不建立评论知识库或持久检索历史；M3 临时入口只用于契约核对，不作为独立产品功能。

## 出站与未验证项

首次联网前告知该第三方站点并取得授权；只发送必要课程/教师关键词，不送学号、学校密码、整份课表或用户日程。来源链接和点评文本是不可信数据，不能提供新目标、脚本或权限。不得执行点赞、收藏、发布、修改等业务动作。

每作业使用独立匿名 Dart HTTP 客户端，尊重 7897 代理环境，无 Cookie/学校认证资产；HTTPS、固定来源/路径/参数及最终请求意图逐跳复验。正文解压后每页最多 2 MiB、最多 8 次重定向、作业最多 60 秒；连接中断最多再尝试一次同一匿名只读 GET，保留原预算，拒绝/非成功状态/结构错误/取消不重试。点评快照及每次输出有界，长点评支持受控续读。取消、过期引用、结构错误、合法空态和网络失败分别返回，收口失败保留全局租约直至恢复。

本机匿名请求仍出现过 TLS EOF/networkFailed；有限成功样例不能保证站点或代理一直可达，不自动换浏览器、降低 TLS 或借用登录。固定课程空态须匹配真实搜索词及“没有匹配到任何课程或老师”节点，不能以空 DOM、点评搜索空态或传输失败当课程无结果。真实限流及其他尚未观察的错误形状保持未观察，实际失败与修复见阶段记录。

实际研究、修复及检查分别见 [材料研究](../../milestones/m3/records/02-public-materials.md)和 [内部实现记录](../../milestones/m3/records/04-internal-implementation.md)。本参考中的课程编号是公开站点示例，不是用户账号、个人选课或评分数据。
