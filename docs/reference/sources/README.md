# 来源契约参考

这里维护各来源当前具体行为。通用身份、文档、凭据、许可和事务要求见[09 关键契约](../../architecture/09-contracts.md)；已知平台与服务限制见[已知问题](../../releases/known-issues.md)。

| 来源能力 | 当前参考 | 已知限制 |
|---|---|---|
| JW 课表/考试同步 | [JW](jw.md) | 非空考试与覆盖范围需按[已知问题](../../releases/known-issues.md)理解 |
| Young 活动关联日程同步 | [Young](young.md) | 活动关联不独立证明本人报名或取消状态 |
| Young 报名活动只读查询 | [Young](young.md) | 查询结果不导入日程，也不执行报名操作 |
| 评课公开查询 | [评课](icourse.md) | 网络可达性、课程覆盖与未观察响应形状有限 |
| 校园公开查阅与长期知识材料 | [教务处/财务处](campus.md) | 财务关键词和 FAQ 不可用；政策现行性未知；时效通知不入知识库 |

账号/业务 ID、秘密、原始响应和浏览器资产不进入这些文件。新增来源须先明确其访问范围、身份、隐私、失败和完整性约束，再维护具体契约和实现。

Agent 的独立网络出口见[模型网关](model-gateway.md)，含学校及可选 DeepSeek 官方服务。它不属于五条业务来源；每个提供方的真实能力需分别核验。
