# USTC Assistant 只读 Agent 人工验收清单

本清单由用户在真实校园网、Panabit iWAN 和学校模型服务环境下逐项执行。每一项末尾的
`完成：`留空，由用户在真实验收后填写安全的结果文字（成功 / 失败 / 原因简述）。

## 前置约束

- 真实 API Key 只通过 App 的“设置 → 模型服务”界面输入；不写入本文件、源码、日志或截图。
- 不得在本文件中记录真实 API Key、完整学校账号、私人课表标题、原始模型请求/响应、
  Cookie、Token、密码或验证码。
- 验收截图不得包含 Key、完整账号、私人日程或原始模型请求；只记录脱敏的成功/失败文字。
- 学校 API 与学校网站是人工验收依赖，不进入自动测试。自动测试通过不代表人工验收通过。

## 3. 现有代理 + iWAN + 学校 Host 直连

学校 API Host 由 `AnthropicLlmProvider` 固定为 `https://api.llm.ustc.edu.cn`，
不在 App 内提供 Host 配置项；篡改的 Host 会被拒绝（`protocol_error`，不发请求）。
当前外部代理与 iWAN 同时开启且影响校园路由时，由用户在系统层面将学校 API Host
走直连（例如在系统代理或 PAC 中为该 Host 配置直连），App 不启动、配置或管理系统
代理、TUN 或 iWAN。

- 在外部代理开启状态下执行连接测试，确认是否需要直连配置：完成：
- 在系统层面将学校 API Host 走直连后再次测试，确认连接恢复：完成：
- 确认 `127.0.0.1` 和 `localhost` 本地 Bridge 不经过外部代理：完成：
- 确认不忽略 TLS 证书错误：完成：

- 同步状态：询问同步状态，确认 `get_sync_status` 返回来源和最近成功/失败时间，Agent 只建议前往同步页、不启动同步：完成：
- 二课报名中：查询当前报名中活动，确认 `search_current_second_class_activities` 返回活动列表：完成：
