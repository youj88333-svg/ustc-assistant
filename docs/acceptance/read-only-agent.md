## 前置约束

- 真实 API Key 只通过 App 的“设置 → 模型服务”界面输入；不写入本文件、源码、日志或截图。
- 不得在本文件中记录真实 API Key、完整学校账号、私人课表标题、原始模型请求/响应、
  Cookie、Token、密码或验证码。
- 验收截图不得包含 Key、完整账号、私人日程或原始模型请求；只记录脱敏的成功/失败文字。
- 学校 API 与学校网站是人工验收依赖，不进入自动测试。自动测试通过不代表人工验收通过。
