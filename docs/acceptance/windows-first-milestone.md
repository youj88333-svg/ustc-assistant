# USTC Assistant Windows 首版手工测试

本文用于逐步验收 Windows 首版。它描述的是预期行为，不代表相应功能已经通过测试。

## 填写规则

- 每项测试结束后，在“完成：”后填写 `成功`、`失败`、`跳过` 或 `不适用`。
- 失败时同时记录简短现象，例如：`失败；教务同步成功，但周视图为空`。
- 不要在本文中记录学号、密码、验证码、Cookie、Token、完整姓名或浏览器 Profile 路径。
- 遇到失败可以继续测试不依赖该功能的项目；依赖项无法满足时填写“跳过；依赖第 N 项”。
- 涉及删除的测试全部放在最后。执行前确认已经完成其他测试。

## 一、启动与基础导航

### 1. 启动应用

1. 打开 PowerShell。
2. 执行：

   ```powershell
   cd E:\107\.worktrees\first-windows-milestone
   conda activate ustc_assistant
   .\app\build\windows\x64\runner\Release\ustc_assistant_app.exe
   ```

3. 若 Release 程序不存在，改用：

   ```powershell
   cd E:\107\.worktrees\first-windows-milestone\app
   E:\flutter\flutter\bin\flutter.bat run -d windows
   ```

预期结果：

- 应用正常打开，不出现闪退或空白窗口。
- 首屏为“聊天”。
- 聊天输入区明确处于尚未接入智能体的禁用状态。

2. 再点击“聊天”。

## 二、账号与教务同步

### 4. 首次绑定账号

如果当前已经绑定账号，本项可以跳过，留到第 28 项完成重置后再测。

1. 打开侧边栏中的“同步”。
2. 确认页面显示“绑定学校账号”。
3. 输入学校账号。
4. 密码可以留空；若输入密码，按需勾选“保存密码”。
5. 点击“登录并同步教务”。
6. 出现“需要登录学校网站”时点击“继续”。
7. 在自动打开的可见 Edge 中完成学校登录和验证码。
8. 等待应用完成同步。

预期结果：

- 点击登录后 Flutter 应用不退出、不闪退。
- Edge 只在用户确认后打开。
- 密码留空时允许在学校页面手动输入。
- 成功后提示“账号已绑定，教务同步完成”。
- 同步页面进入已绑定账号状态，不再显示首次绑定表单。
- 登录失败时显示脱敏错误码，不显示密码、Cookie 或完整网页响应。

完成：1

2. 查看账号提示、保存密码状态、教务系统状态和二课平台状态。

预期结果：

- 只显示脱敏账号提示，不显示完整学校账号。
- “已保存密码”与第 4 项选择一致。
- 教务系统显示最近一次同步成功时间，而不是“等待同步”。
- 二课尚未同步时可以显示“等待同步”。
- 时间含义与北京时间一致。

完成：1

5. 检查同一课程在不同周是否使用一致颜色。

预期结果：

- 周一至周日均属于周视图范围。

- 不同课程可区分，同一课程颜色一致。

## 七、失败恢复与安全

### 32. 取消登录

1. 清除专用浏览器会话后发起一次同步。
2. 出现“需要登录学校网站”时点击“取消”。

预期结果：

- 不打开 Edge，或立即停止尚未开始的交互采集。
- 状态显示“已取消”，不导入部分结果。
- 上一次成功数据继续显示。

完成：1

### 33. Bridge 或浏览器中断

1. 发起一次需要 Edge 的同步。
2. 在采集尚未完成时关闭 Edge。
3. 观察同步结果和应用状态。
4. 再次手动同步。

预期结果：

- Flutter 应用不随 Edge 或 Bridge 异常退出。
- 中断任务不导入部分 Bundle。
- 错误提示和历史记录均脱敏。
- 随后可以重新同步并恢复。

完成：1

### 34. 账号不一致

本项需要另一个可登录学校账号；没有时填写“不适用”。

1. 当前应用绑定账号 A。
2. 清除浏览器会话后发起同步。
3. 在学校页面登录账号 B。

预期结果：

- 应用识别账号不一致并拒绝导入。
- 账号 A 的已有数据不被账号 B 覆盖。
- 不生成归属不明的 SourceBundle。

完成：不适用

### 35. 本地持久化与敏感信息

1. 完成至少一次同步、创建个人日程和创建 Task。
2. 关闭应用并重新打开。
3. 检查日程、Task、来源状态和设置。
4. 不打开或传播数据库内容，只在本机使用字符串搜索工具检查是否存在你刚使用的完整账号或密码。

预期结果：

- 业务数据、来源状态和设置在重启后保留。
- SQLite 中不含学校账号或密码明文。
- 学校账号名和可选密码由 Windows DPAPI 保护。
- Bundle、日志和错误中不含远端个人 ID、Cookie、Token、验证码或浏览器路径。

完成：1

## 八、破坏性测试

以下项目会删除本地状态，务必最后执行。

### 36. 删除安全凭据

1. 打开“设置”。
2. 点击“删除安全凭据”。
3. 先点“取消”，确认无变化。
4. 再次操作并点“确认”。
5. 打开“账号”和“同步”。

预期结果：

- 必须显式确认后才删除。
- 删除凭据不等于删除业务日程。
- 已同步课程、二课、个人日程和 Task 仍在。
- 下次同步要求重新登录或重新输入凭据。

完成：下次同步未要求重新登录，而是没反应

### 37. 清除专用浏览器会话

1. 打开“设置”。
2. 点击“清除专用浏览器会话”并确认。
3. 再次同步教务或二课。

预期结果：

- 浏览器会话与保存凭据是两个独立开关。
- 清除会话后再次同步需要学校登录。
- 本地业务数据不被删除。

完成：实际上每次同步都需要浏览器会话登录，已经进行36后不适用

### 38. 清除业务数据

1. 打开“设置”。
2. 点击“清除业务数据”。
3. 先取消，确认数据仍在。
4. 再次操作并确认。

预期结果：

- 取消不会修改数据。
- 确认后日程、Task 和本地修改被清除。
- 安全凭据和浏览器会话不应被此单项操作连带清除。

完成：1

### 39. 完全重置

1. 打开“设置”。
2. 点击“完全重置”。
3. 在第一次确认后，于第二次确认选择取消，检查数据仍在。
4. 再次执行并完成两次确认。
5. 关闭并重新打开应用。

预期结果：

- 少于两次确认不得执行重置。
- 完成两次确认后，账号、凭据、来源状态、业务数据、设置和浏览器会话均恢复到首次使用状态。
- 重启后同步页重新显示“绑定学校账号”。

完成：不会跳转到登录页
