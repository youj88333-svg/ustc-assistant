## 重点决定

- [可选 DeepSeek 官方模型服务](model-providers.md)：学校与官方两套固定配置/同意/受保护 Key 隔离，手工切换且不自动回退，官方直答与现有工具兼容。

- [DR-ADR-09：首版浏览器边界](dr-adr-09-browser-boundary.md)。
- [DR-ADR-10：本地 M0 分段准入](dr-adr-10-local-m0.md)。
- [学校账号与凭据共享](school-credentials.md)：2026-10-10/11 的明确授权，延续既有保护用途。
- [来源场次退出有效日程](source-occurrence-retirement.md)：完整本次范围内不再返回的旧课程或二课活动关联日程退出有效投影，正常历史学期及所有用户覆盖保留。
- [校园长期 Markdown 知识库与 M3 边界](public-text-knowledge.md)：未来 Agent 公开查询的内部基础，无独立用户入口或工具注册，允许临时验收；长期资料开发校核、时效通知仅在线、评课在线及校园 IP 直连，转换工具不装配应用。

新重要决定按背景、决定、状态、依据和后果记录。普通修复只写阶段记录；未批准的方向保持提议，不让 ADR 代替用户决定。

## Android兼容修订

- [Android普通系统WebView兼容修订](android-system-webview-compatibility.md)：2026-10-17获用户批准，以普通系统组件、独立宿主/目录及固定页面脚本保留自动认证与采集；在Android映射内替代私有世界、全frame覆盖和残留清理阻断的相应强约束。Windows和其余通用不变量保持。
