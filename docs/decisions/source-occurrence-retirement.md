# 来源场次退出有效日程

状态：已采纳，2026-10-15。用户针对教务调休及二课日程消失的残留问题，明确要求不同学期互不误删后授权“请修复这个问题吧”。本决定替代 DR-ADR-05 中“来源缺失仍作为有效安排、保留提醒与冲突”的部分；原批准与历史验收记录不改写。

## 背景与决定

只更新来源观察标签会使学校调整前的场次继续占据日历和空档，并继续提醒。若直接排除所有范围外记录，又会误伤其它学期；单一观察标签还会在后续查询别的范围时覆盖曾经缺失的结论。

采用独立持久的来源有效性事实：仅在成功完整同步的范围内停用未返回的旧场次，默认有效投影统一排除，保留历史和用户决定。范围外不重新推断有效性，同稳定键再次返回才恢复。确切范围、恢复、考试例外及消费者规则以 [09 K-05](../architecture/09-contracts.md#k-05-完整快照事务与缺失展示)为唯一契约；升级兼容见 [K-06](../architecture/09-contracts.md#k-06-数据连续性与维护)。

## 后果与保留边界

- 不物理删除来源行，不把失效写成用户隐藏、出勤或完成；正常历史学期仍在原日期可见，历史失效项可主动查阅。
- 不能把未返回解释成学校已取消课程或独立验证了二课取消报名；考试缺少可靠完整范围，维持原边界。
- 升级保留全部资料。旧观察标签若已被其它范围同步覆盖，不能还原消失事实，须重新同步对应范围；不通过访问正式业务行补造历史。
- 工程、迁移、提醒撤销及 Windows 检查与真人来源结果分开记录，见 [Windows 收尾记录](../milestones/windows-polish/records.md)。
