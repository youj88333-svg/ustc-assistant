# 校园精选文本知识库与 M3 边界

状态：用户 2026-10-11 明确长期文本范围，并进一步限定为未来 Agent 查询公开信息的内部基础；无独立用户入口，M3 不生成或注册 Agent 工具，允许临时界面验收。2026-10-12 用户批准按修订设计恢复：先定内部接口与首批长期目录，再实现和验证。本决定替代初稿的财务后续/仅链接/不存全文、中途运行时 OCR 和独立查询界面解释，不覆盖早期记录。

## 背景与依据

用户先指定教务通知、学生事务，随后明确将财务处纳入本次范围，要求深入探索教务处、财务处和评课社区，并排除 M3 的 Agent 功能。公开探索发现必要办事说明可能仅在流程图或 PDF 中；单读网页正文无法覆盖这些内容。

用户进一步提出提取必要文件和图片建知识库，并在范围选择中确认“教务、财务精选资料入库；评课在线查询”，之后要求“所有都转化以文本形式构建知识库”。这授权对选定公开材料进行内部临时获取和文本提取，不再将附件一律限定为只给链接。用户先前要求不提供文件下载功能、由用户自行下载原件，继续保留。

用户还说明本机实际在校园网，代理端口 7897 可能触发校外 IP 判断；遇此类限制应绕代理用本机 IP。这是固定校园请求的按需直连授权，不是账号登录授权或修改全局代理的指令。

用户随后明确：OCR 较难内容直接交 Luna / max 形成完整描述，知识材料可用 Markdown；可以参考其 MinerU 技能帮助构建知识库，但不为项目应用配置 MinerU。最后限定“仅仅把一些长期可用的东西做成知识库”，本科老生缴费通知、选课通知等时效消息须明确排除。

用户随后暂停具体实施，并明确搜索、读取和知识库最终均通过 Agent 暴露给用户；M3 不作为独立用户功能，也不直接生成 Agent 工具，但须便于后续工具接入，可以创建临时人工验证界面。此前“本期无 Agent”落实为不实施模型/工具层，不能解释为内部能力不考虑 Agent 消费。

## 当前决定

- M3 交付内部评课在线查询、教务/财务公开检索/读取及精选长期 Markdown 知识库，为未来 Agent 使用；不提供独立搜索/资讯/知识库产品入口，不生成或注册 Agent 工具，不装配模型生成、向量库或 MinerU/云端 OCR。
- 内部接口与模型/界面分离，返回有界候选、片段/正文、受控引用、出处/版本/时间、实际覆盖与明确失败；检索与按引用读取分开，后续 C4 适配工具和安全结果投影，复用查询逻辑。临时界面只调用同一接口验证，不决定业务规则或扩大许可；M3 关闭不等于工具/对话通过。
- 只入长期流程、制度、服务说明、FAQ 和版本明确的手册；当期缴费、选课通知、报名/申请窗口、截止日公告、活动和新闻不入库，在线查阅与材料入库分开。通知引用的长期制度须作为独立材料另核对，不能整篇带入。
- 开发时用 MinerU 预处理公开材料，困难图示/表格交 Luna / max 写完整 Markdown，Sol 对照原页核验；转换完成不等于内容完整。正式材料只保留必要文本、表格/步骤/条件和出处，不携带临时图片引用；评课评论不批量入库。
- 原始公开 PDF/图片只作为受控临时输入，不长期归档，不进入 Git、日志或发布包；C3 管理持久文本、片段、派生索引与回执，不建立文件目录作为第二持久事实源。
- 知识库保留当前接受版本。刷新失败保留旧文本并说明状态；成功的新版本原子替换当前正文/索引，不默认保存所有历史全文。单独清知识库保留学校来源资产，完全重置明确包含知识库。
- 实际需要账号登录的内容跳过，评课不接入独立账号。明确的校园 IP 限制先按授权用同一受控客户端直连重试；每跳/目标、TLS、内容和资源限额继续有效。不能仅凭 403 认定 IP 限制，也不使用浏览器会话资产解决公开请求。

## 后果与落实

M3 增加开发时转换/视觉校核、版本化内部检索与证据契约、中文全文检索、临时 Markdown 预览、版本载入/事务及维护验收，适用 V-04/V-06/V-08。校核 Markdown 是应用材料输入，C3 管理当前事实；无需为 Windows 或未来移动端装配转换服务。制作工具只处理选定公开资料。C4 后续负责模型可见工具、参数映射、授权与安全结果投影，C5 正式呈现 Agent 对话及引用；M3 只准备可复用能力，不实现模型/Key/工具循环，也不因内容与 Agent 强相关提前接入。

工程约束见 [09 K-07](../architecture/09-contracts.md#k-07-公开文本材料与知识库)，范围和关闭条件仅在 [M3 任务单](../milestones/m3/plan.md)维护。事实与未知项见 [校园参考](../reference/sources/campus.md)、[评课参考](../reference/sources/icourse.md)和 [研究记录](../milestones/m3/records/02-public-materials.md)。未证明的原生能力、内容完整性和产品实际链路继续保持未验证，不因本决定关闭里程碑。
