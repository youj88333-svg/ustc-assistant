# DR-ADR-09：首版浏览器边界

状态：已采纳，2026-10-09。依据：用户先批准有限边界，随后回复“approve，请修改设计”，将严格浏览器网络隔离移出首版；原审核及批准记录见 [14 第 8 节](../reviews/14-overall-review.md#8-首版边界调整与本地-m0-准入)。

## 背景

严格隔离前置实验存在协议漏拦与 CAL 后续导航原生崩溃。继续要求完整协议封闭及补丁运行时会阻止已可用的普通 WebView 来源链路。实验失败保留在 [Windows 记录](../../verification/windows/README.md)，没有修饰为通过。

## 决定

首版采用普通 WebView，接受页面正常后台网络，尊重页面原有策略。保留精确导航/frame、弹窗、下载、权限申请、外部协议、固定操作、独立分区/文档关联、凭据保护和排空真清理。

不主动注入 CAL、安装全协议防护扩展、一律禁 Worker 或替换 WebRTC；CAL 修复、补丁资格和全协议漏拦回归移出 M0、来源观测、冻结/发布门槛，不主动追版本。应用自有出站仍限定目标、必要字段和授权，主动学校业务只读，Agent 无任意浏览器执行能力。

## 后果

不承诺网页全部协议白名单或零外联；来源身份、响应/完整性及保留控制继续分别验收。实际学校兼容性故障按具体证据修复，不以放宽页面已有策略规避。当前规则由 [07](../architecture/07-constitution.md#首版浏览器安全边界与-m0-准入)及 [09 K-03](../architecture/09-contracts.md#k-03-文档关联与受控动作)落实。
