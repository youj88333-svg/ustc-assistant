状态：2026-10-12，用户已验收并关闭 M4.1，授权开始 M4.2，先明确日程与个人安排的范围、接口契约及验收条件。M4.2 按下节规格实施；M4.3、M4.4 与 M5 未开始。默认 Agent、两主页、日程内任务及只读 main 界面参考继续有效；[验收](acceptance.md)与[过程记录](records.md)分开维护，不沿用冻结档案中的旧里程碑。

## 目标与依据

M1–M3 已完成各自批准范围的来源接入和内部能力，后补与未观察项按原登记保留。M4 将现有工程整理为没有模型也能日常使用的 Windows 应用：正式导航、日程/任务、来源与维护设置、Agent 空壳，以及支撑这些交互的本地业务服务和增量数据库模型。

“接入前准备”限于这些可独立验收的应用能力和必要接口，不扩展为所有非 Agent 功能、所有平台或整体设计冻结。M5 拟在这些服务上增加真实模型调用、对话、工具/授权和执行闭环；其运行状态、历史/批准语义及模型相关存储在 M5 单独定稿。M3 的公开查询与知识库仍只提供内部能力，正式检索/问答入口通过未来 Agent。

## 已批准范围

| 业务 | 本阶段边界 |
|---|---|
| 应用壳与导航 | 默认 Agent，主导航只有 Agent/日程；日程内分日程/任务栏目，设置为侧边栏底部辅助入口。加载/空态/忙碌/学校人工接续/失败/恢复状态清楚；现有阶段诊断面板退出日常主流程，调试入口受控保留 |
| Agent 空壳 | 完成对话区、输入区和空态布局，预留状态/引用/操作卡的展示接入点；未接入时发送不可用且说明状态，不生成伪回复、不保存真实对话或调用模型。实际对话、工具批准和历史语义属于 M5 |
| 统一日程 | 日期列表与周视图使用同一有效投影，汇合学校日程、个人事件和任务时间块；必要来源/缺失状态、隐藏恢复、详情和筛选一致，不以刷新或范围移动删除已知记录 |
| 个人事件 | 新建、修改、删除与完成确认；单次、全天、跨日、基础每周重复和单次修改/跳过。整组编辑与单次例外的影响需明确，查询只按窗口有界展开；复杂节假日规则和无限系列展开不纳入首版 |
| Task 与 PlanBlock | 任务的基本内容、截止时间和人工状态；任务可有零个或多个规划时间块。创建/移动/删除时间块不直接改变任务完成状态；时间块结束不自动完成任务。支持手工安排，不做模型或算法自动排程 |
| 用户解释与本地记录 | 课程/二课的出勤决定、听讲方式和备注按适用业务分开；定时重叠默认冲突，用户可确认冲突/明确不冲突并保留原因，全天排除。学校来源刷新不得覆盖这些决定 |
| 本地写与撤销 | 上述单项及必要的任务/时间块组合写通过同一版本化业务命令，保留事务回执和必要安全审计。成功修改提供受版本守卫的撤销；后续已改变目标时报告冲突，不能回滚整个数据库或覆盖新导入。具体撤销范围/额度/保留期在实现前定稿 |
| 来源与设置 | 在正式设置中复用学校密码、学期/日期范围、同步与取消/恢复、来源状态和界面偏好。资料维护只提供固定版本载入/计数/清理，不增加公开检索产品入口。凭据/分区/本地业务/知识库清理及完全重置按已有保留规则明确范围和确认；模型配置可留布局，实际 Key 与网关校验在 M5 实现 |
| 本地数据与前后端服务 | 完成支持上述行为的模型、查询/写服务、分页/窗口投影、状态通知与必要索引；增量迁移保留已有事实，不以“优化”为名重建数据库。性能问题先测量再修正；不预建未知 Agent 历史或工具表，不为了抽象重写已验证的来源链路 |

## 后续范围

M5 拟负责真实 Agent 对话、学校模型网关/Key 使用、工具注册/调度、模型上下文/出站隐私、写操作批准与历史生命周期；M4 只交付可独立使用的业务查询/命令接口和展示组件，不借空壳提前调用模型。M5 的自动规划与长时间运行是否首批交付，仍需单独划定范围。

系统通知及应用关闭后的提醒调度具有独立的平台可靠性边界，建议另立后续阶段；不将其视为 Agent 接入前的必须依赖，也不在 M4 界面显示未经实现的能力承诺。

移动端、云同步、多账号、备份导出、文件下载、扩展知识材料和学校写操作均不作为本期交付。原总体批准范围及学校只读边界保留，M3 不可用项继续如实显示，不用本期范围讨论改写过去证据。

## 接口与不变量

- C3 提供统一日期查询、事件/任务/时间块详情、冲突候选及受控本地写；对未来消费者输出类型化对象和稳定状态，不依赖 Widget 或模型，C5 不再维护第二份日程规则。
- 正式页面和未来 Agent 调用同一业务服务；前后端按明确的输入、结果/状态、失败和更新通知配合。M4 的 Agent 布局占位不产生新的网络通道、来源租约、工具授权或真实历史存储。
- 写意图绑定操作身份、当前本地上下文/账号、reset epoch、目标版本及必要确认；提交内复验维护状态、所有权和幂等。重放只返回提交回执，变更意图不得沿用旧批准；未知目标/引用和版本冲突明确失败。
- 学校事实由同步更新，用户安排与覆盖独立；同步保留本地身份、隐藏、备注和冲突解释。来源缺失仍参与原日期内日程/冲突投影，全天/日期与时刻使用北京时间明确区分。
- Task、PlanBlock、个人事件完成状态分别由明确用户意图驱动；学校结束、计划到时或来源刷新不能替代用户完成确认。删除/撤销对关联时间块的影响必须在规格中明示。
- 写、必要回执/审计同事务；失败和取消保留已提交事实。清理/重置作废旧意图并排空，不能由迟到回调重建已删除内容；学校凭据、分区、目录及 M3 文本不属于普通日程修改/撤销范围。

## 依赖、施工与验收

批准后由 Sol 先明确页面信息架构和业务服务边界，确定时间/稳定身份、重复与例外、Task/PlanBlock 关联、删除/撤销和增量 schema 映射；不要求先写完所有后端才开始界面。每个子阶段按可用场景同时交付相关服务与交互。契约确定后 Luna / max 可承接布局/表单、纯投影或场景验证，共享契约/迁移/事务由 Sol 单一写入；文件互不重叠才并行。允许修改仅当前工作区必要 app/ 与文档，不读正式记录、不碰其他 worktree、不推送。

各子阶段可建立独立 Git 检查点和验收记录，但仍只维护本任务单。布局与既定业务契约可确定后并行小块；共享模型或事务的依赖顺序不能靠“前后端同时做”跳过。本稿未定的参数不直接交子代理猜测。

| 验收 | 完成条件 |
|---|---|
| 应用可用与 Agent 交接 | 无模型也能导航、同步已有学校来源、看日程、管理个人安排/任务和设置；空态/错误/恢复可理解。Agent 空壳明确未接入，M5 可消费同一业务端口与展示组件；不假称工具/历史/隐私已通过 |

| 数据与故障 | 当前 schema 增量升级保留 JW/Young 日程及覆盖、密码、目录、分区许可和 M3 资料；失败/取消/重复/版本冲突/维护迟到写及撤销不覆盖新版本有合成/原生证据 |

批准的总边界是“Windows 应用壳与本地业务可用，Agent 接入点已准备”；完成标准不是“所有非 Agent 功能都实现”。M4 不需提供模型 Key。M5 正式 Agent 是下一阶段方向，尚未定任务单或开始实施。

## M4.1 已定布局与接口规格

### 页面与视觉

只读参考 main 工作区的 `app_drawer`、默认 `/chat`、日程内周视图/任务分栏和对话区居中布局；只取信息组织/交互经验，不移植其代码、数据库/资料、依赖、模型调用或旧通过结论，不改其未提交内容。当前工作区独立实现。

采用浅色桌面布局，低饱和墨绿主色、灰白背景、清晰文字层级、适度留白及一致圆角/边框。宽窗口固定左侧导航与右侧工作区；中等宽度压缩导航，窄窗口使用抽屉，内容仍能滚动操作。两主入口始终为 Agent、日程；设置在导航底部。保留系统窗口关闭与当前排空流程。

- **Agent（默认）**：居中空态和底部禁用输入/发送区，明确模型尚未接入，提供“查看日程”和“管理来源”的可用跳转；不显示模拟对话、保存消息、请求 Key 或注册工具。
- **日程**：页内日程/任务切换。日程先交付北京时间日期导航、日期选择、来源筛选、已有记录列表、详情及既有隐藏/恢复；默认今日，合法空日与本地资料尚未读取分开。周网格、个人事件及复杂编辑在 M4.2；任务页为清楚的占位，业务在 M4.3。
- **设置**：先交付教务/二课来源切换、密码主动提供与保存选择、课表学期/二课日期范围、同步/活动查询、人工接续/取消/收口重试及既有登录资料/共享密码清理。复用现有正式端口，不新增账号、知识检索入口或跨来源自动连锁同步；完整维护/偏好在 M4.4。
- **诊断**：普通构建不显示旧观测、契约探针、M0 演示和 M3 公开查询入口。显式开发构建可在设置内装配可选诊断区；进入/离开主页面不取消或重开来源，不使临时公开入口变成产品导航。

### 端口与责任

| 契约 | 输入/输出与归属 |
|---|---|
| local-agenda-v1 | C0 定义日期/来源/观察状态、内部稳定引用和只读列表；C3 统一投影当前已接受 JW/Young 数据。按北京时间日窗口 `[start,end)` 与来源筛选，跨日重叠按区间交集，缺失记录保留，隐藏只有显式选项改变；最多返回 500 条，匹配/本地总量/截断与资料未就绪分别表达，不承诺学校新鲜度 |
| AppShellPort / AppShellView | C5 订阅既有 JW/Young 状态并提供统一展示、今日日期、查询/隐藏委派。只持有安全状态和本地展示对象，不读写 SQL/文件、认证资产或旧工程数据；导航和空壳不创建来源作业 |
| JwSyncPort / YoungSyncPort | 同一正式 C2/C3 端口继续处理同步、查询、人工挑战接续、取消、恢复、密码删除、分区清理与受版本守卫的隐藏；新页面不得另写身份、学期、日期和提交判断。普通设置隐藏诊断参数/摘要，显式诊断保留旧行为 |

日期值使用 UTC 年月日分量表示北京时间日历日期，与 UTC 时刻明确分开；今日从时刻加八小时获取。引用绑定来源、localId 与版本，JW/Young 同值 ID 不合并，隐藏委派先核对仍为当前版本，再由 C3 复验权限/事务。标题、位置和日期是本地用户展示数据，不进入安全摘要/日志。

全局租约继续唯一：应用壳读取实际 WorkLeasePool 与各端口状态，新作业/清登录资料/删除共享密码在其他作业忙碌时禁用；持有者自己的继续/取消/恢复按钮保持可用，C2/C3 仍是最终裁决。提交事实与待恢复分别显示，不把取消记为撤销已保存数据。进度订阅失败显示固定警示并拒新的写/来源操作，保留可读取的旧本地事实；页面卸载只清输入/订阅，不关闭作业，返回后用当前状态接续。凭据输入在提交、离开或控制器更换时清空，不回填保存秘密。

### 修改范围、协作与本切验收

Sol 单一写入 C0/C3 投影契约、C5 状态适配/组合根、阶段文档与原生集成核验；不改既有来源认证/采集/事务 schema。Luna / max 按固定端口承接应用壳/Agent与日程展示，以及独立来源设置/既有面板产品投影，限定互不重叠的文件和相关合成 Widget 检查；根复核实际差异与行为后集成。每份派发显式继承上述 07–15、批准修订、守卫与文件归属。

本切完成条件：默认 Agent、两主导航/日程内任务、底部设置及多窗口宽度无溢出；切页不产生模型/学校请求；本地 JW/Young 同日显示、北京时间/跨日/隐藏/缺失/源 ID 碰撞正确；设置继续向原端口传递原意图，其他来源 busy 时不启动，人工等待/取消/提交后恢复和凭据清空行为成立。合成/loopback/临时 Windows 原生装配证明新壳和已有来源配合，相关 analyze/test/build 与文档检查由根执行；截图只用合成数据。M4.1 的完成不关闭 M4.2–M4.4 或 M5，用户只核对少量实际布局/交互。

## M4.2 日程与个人安排规格

### 范围与确定的语义

本切依据上述 07–15、K-05/K-06、V-02/04/05/06 以及用户已批准的 M4 四段范围；不照搬旧 main 的业务模型或测试。Agent 默认、两主页、任务栏目占位和已验收来源不改变。

- 日程交付日/周两种视图（首次默认本周，周一开始），用同一 C3 日期窗口；北京时间日期导航、来源筛选、全天行、跨日分段、详情及隐藏恢复一致。窄窗可横向浏览周列，也可切日列表；不以隐藏当前范围或切页删除事实。
- 个人事件不要求学校登录，可新建、整项/整组修改、删除和明确完成确认。时刻使用 UTC 微秒；全天保存北京时间日期分量区间 `[开始日,结束日不含)`，界面显示包含式结束日期。标题最多 200 字符、地点 200、备注 4000，跨度最多 366 天，拒空标题/零或负跨度；不自动在结束时完成。
- 基础重复先定为**每周一次，星期由首日决定**，可选包含式截止日，无截止也只按查询窗口展开。稳定 occurrence 是 `(seriesId,ordinal)`，单次为 0，每周第 n 次为 n；时间、标题、完成与版本不进入稳定身份。
- 单次修改保存完整替代内容及绝对日期/时刻，完成与跳过独立保存。修改整组首日/时刻保留序号及例外，未覆盖项移动，已经单次修改的内容/时刻保持；缩短截止或转单次使超范围序号暂不投影，记录保留，扩大范围后恢复。删除整组是明确确认后的删除标记，旧引用拒绝；本切无恢复/撤销入口，完整清业务/重置在 M4.4 按范围物理清理。
- 可只修改/跳过/恢复一个 occurrence，不混同整组删除。跨远距离移入本周的例外独立纳入候选，先以稳定身份替换再求区间交集，不能只展开当前周的基础项。
- 学校事实不接受用户改标题/时间或完成；继续保存显式 hidden。来源覆盖增加备注，课程/二课可记“未决定/计划参加/不参加”，课程另记“未设置/听讲/自主学习”；这是用户计划，不宣称学校出勤事实，三个字段互不自动推导。考试仅备注与显示。来源刷新、缺失、范围移动/再次出现保持这些独立覆盖。
- 定时相交默认展示为冲突，端点相接不算。范围覆盖同一窗口内全部未隐藏/未跳过的定时项，含来源缺失及已完成个人项，不被展示来源筛选缩小；全天不参加重叠处理。用户明确标记“不冲突”解除默认，也可确认“冲突”并记原因；派生默认与已保存的用户判断分开，不自动写入确认。判定按稳定双方身份保留；改时后不再相交不删除解释，失活 occurrence 暂不作活动事实。
- Task/PlanBlock、受控撤销、复杂 RRULE/节假日/无限展开、拖拽自动排程、提醒、公开产品检索、模型与工具注册不在本切；其中前两项在 M4.3。本切不重写学校认证或采集。

### 接口与事务

`LocalCalendarPort` 为 C3 独立于 Widget/模型的 `local-calendar-v1` 能力，附在唯一 `JwStore`，共享事务队列和所有权。C5 新日程页及未来消费者使用同一查询/命令；旧 M4.1 投影仅兼容旧测试/诊断，正式日程不再拼 JW/Young 协调器缓存。

| 接口 | 输入、输出与守卫 |
|---|---|
| query | `CalendarQuery(firstDay,endDayExclusive,filter,includeHidden,includeSkipped,limit)`，1–62 天、最多 500 项；一次一致 C3 读取返回窗口、列表、日分段、匹配/截断及最多 200 对重叠候选。底层 5000 条各类输入/20000 展开候选预算；学校记录先按请求窗口或明确详情目标读取，窗口外大量保留事实不使当前空窗口失效。超额拒绝为 limitExceeded，不显示合法空或假报完整。冲突截断独立说明 |
| detail | 读取时签发的 `CalendarReference(context,identity,version)`，复验上下文、类型、有效序号及版本；返回当前 occurrence、个人整组原稿、是否有单次替代内容及已存关系。转单次后保留替代内容时，界面编辑当前内容与设置原始重复分别调用对应命令，不以整组保存冒充当前项已修改。未知/失活/过期明确拒绝，不能把旧引用换绑到最新 owner/epoch |
| prepare / commit | C3 准备不可变操作身份/上下文/意图；commit 返回 committed 回执或固定失败。相同命令重放只返回原回执，改意图为 idempotencyConflict；重放仍复验当前上下文/维护，不将历史回执当当前资料 |
| 个人命令 | 新建、整组/单次修改、完成/跳过、明确确认删除；变动一个 occurrence 也递增系列版本，使并行旧编辑显式失效，绝不暗合并旧表单 |
| 学校覆盖/关系命令 | 覆盖只改适用字段并递增当前记录版本；关系新增/修改复验双方当前版本，修改/删除还绑定关系版本。任何一方过期整个事务拒绝，不做部分写 |
| changes | 提交后仅广播安全 revision，不带账号、标题、备注、引用或原文；来源协调器变化触发 C5 重新查同一窗口，不广播正式业务载荷 |

个人安排上下文取 C3 的持久 owner/resetEpoch 和新增 agendaEpoch，不依赖学校 generation 或伪造账号；首登绑定不作废已有个人安排。学校覆盖另外确认当前业务账号及目标。schema 5→6 仅增量添加 agenda 状态、个人系列/例外、关系、命令回执/安全审计和原学校覆盖字段，不复制 hidden 或重建来源/知识表；保留 1–5 的合法升级链。

现有 `_guard` 只有目录所有权，不能据此声称有维护屏障。本切新增持久 agenda 维护/epoch 守卫，准备、读取、提交前后复验，关闭拒新并排空；完整清理/重置编排与界面仍在 M4.4。必要业务、版本、回执与审计同事务，SQL/所有权/守卫失败回滚；审计只保存固定动作、计数和时间，内部回执不写安全日志。表单/命令上下文从读时捕获，不接受任意 DB id/路径/学校账号作为授权。

新日程端口不以协调器 `Future<void>` 正常返回判断隐藏成功；C3 直接给明确回执/错误。C5 `execute(intent,expectedContext)` 必须携表单打开时的上下文，新建也不能在重置后自动换绑；修改继续携目标读时引用。个人/覆盖写不获得第二个网络通道，C5 在现有来源 busy 或查询/写处理中禁新写，写互斥持续到提交后窗口/详情刷新结束；导航、查看与来源自身继续/取消仍可用，来源与本地写的最终版本/事务由 C3 裁决。C5 所有异步返回校验控制器/查询世代，旧详情/弹窗/加载不覆盖新页。
