**日常自动采集接续规格（2026-10-10，同一 M1 任务，实现完成、真实自动认证待验收）**：用户明确重新输入学校密码不阻塞 M1，要求把主动保存的本地加密账号密码、自动身份认证和采集接成完整日常链路；随后澄清日常流程应包含加密凭据和自动登录，不拆成互斥方向。旧免登录结果继续记为未通过，但不再作为本切准入或 M1 关闭条件。Sol / max 总负责；Luna / max 实现 Windows 凭据保护与明确 UI/合成测试；Astra / high 有界复核密码投递的文档归属，不要求学校永久保留授权。

- **目标和行为**：用户在应用主动输入账号密码并选择保存后，自动进入固定教务认证入口，单次投递和提交密码；验证码、通行密钥及额外授权转回可见学校窗口由用户完成，继续同一作业。登录后固定打开课表入口并读取新目录；首次由用户选择学期，以后仅当上次成功导入的学期仍在新目录时自动选用并采集。不存在时等待明确选择，不默换学期。每次仍复验本人路线、前后业务身份和只读响应，再原子导入；登录动作成功不是身份或采集授权。
- **C3/P 凭据约束**：现有 SQLite v1 无损升级 v2，保留账号、183 条已验收日程、覆盖、两次导入、许可及审计。新增唯一业务库内的 DPAPI CurrentUser 密文及机制元数据、成功导入学期；不另建 vault，不保存明文密码。登录账号和密码整体保护，现有业务身份字段继续服务本人核验。新凭据先保护，仅在真实身份/快照通过后的成功导入事务中替换旧凭据；保护、验证、取消或 SQL 失败保留旧事实。清浏览器资料保留业务数据及主动保存的凭据；提供独立删除保存凭据动作。一次性不可序列化租约用后尽力零化，Dart 不可变字符串不宣称可彻底抹除。
- **密码投递与导航**：仅固定学校认证 origin/路径及单一明确表单接受自动登录；其他页面无秘密投递。先无秘密建立独立环境和私有远端对象，再以该文档对象调用固定函数，逐回调检查 session/document/operation、origin/path，不向可复用的裸 contextId 注入秘密。无法保证对象归属、页面结构改变或挑战出现时返回人工处理，不循环提交密码。沿用复杂逐跳导航控制、页面已有策略和全局单租约。
- **文件和依赖**：Sol 负责共享 core/source/jobs 契约、C3 升级及事务、C2 状态/取消/恢复、固定原生登录和组合；Luna 在契约确定后分别写新 Windows DPAPI 文件/测试及面板/测试，文件不重叠。只修改 app/ 与本任务必要文档，不复制旧来源实现、fixtures 或记录。历史分支仅核对已存在的认证路径与选择器线索。
- **验证和完成条件**：使用全新合成秘密及 loopback 登录页面证明保护/恢复、篡改和错误 purpose 拒绝、v1 升级连续性、原子凭据保存、一次提交、跨文档零误投、人工挑战恢复、目录变化、取消和不重复导入；自动不访问学校。主代理执行 analyze/test/相关 Windows 原生集成/build；真实保存与自动认证需用户在应用内操作并反馈脱敏结果，不在聊天收集凭据。真实非空考试仍未观察，自动证据、此前真人验收与本切真人结果分开登记。

**机制证据范围**：bootstrap 不含秘密，以 `uniqueContextId` 和 `allowUnsafeEvalBlockedByCSP=false` 创建该文档的私有对象；秘密只作为 `Runtime.callFunctionOn` 的固定函数参数送至该 `objectId`。每个回调复验文档、会话和操作；同 URL history 变化也撤销能力，不能只依赖对象通常随导航销毁。CDP 会编译固定 wrapper，`callFunctionOn` 没有 evaluate 的 CSP 开关；本实现不修改页面 CSP，也不支持任意函数、脚本或 URL。固定脚本静态核查只使用原型 value setter，不读取现有密码值；合成 fixture 的页面 getter 计数不能证明跨 world 的读取行为，该计数和断言已移除。依据为 [CDP Runtime 契约](https://chromedevtools.github.io/devtools-protocol/v8/Runtime/)、[V8 对象查找](https://chromium.googlesource.com/v8/v8/+/refs/heads/main/src/inspector/v8-inspector-session-impl.cc)、[V8 injected script](https://chromium.googlesource.com/v8/v8/+/refs/heads/main/src/inspector/injected-script.cc)及 [WebView2 CDP 调用](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2#calldevtoolsprotocolmethod)。DPAPI 当前用户及可选 entropy 行为依据 [Microsoft CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)；本机合成检查不证明跨设备迁移。

- **目标和规则**：首次按北京时间月份从本次学校目录匹配唯一学期（2–6 月当年春、7 月当年夏、8–12 月当年秋、1 月上一年秋），不计算学校 ID；标签缺失或匹配不唯一才等待选择。后续默认上次成功学期，可在同步前从本地目录改选；已指定/记住项若不在新目录则等待明确选择，不静默换期。每次重新读取学校目录，缓存只供界面选择，不能代替本人核验、来源响应或新目录证据。
- **接口和持久化**：`startSync` 接受可选 `semesterId`，开始作业前捕获一次；C3 v1/v2 无损升级 v3，新增有界目录（最多 256 条，ID、名称、学校默认标记及更新时间）。目录先随作业暂存，仅和经本人核验的成功导入同事务保存；失败/取消保留旧目录、成功学期、凭据和业务数据。清分区、删除密码不删除目录。
- **协作和文件**：Sol 总负责共享目录/月份策略、DTO、C2/C3、迁移、原生完整链路与集成；Sol / max 子代理调查公开未认证页面并修复固定原生认证和独立合成夹具；Luna / max 仅负责面板/测试及另一个不重叠的目录/迁移测试文件。SDK 检查由主代理顺序执行，不复制旧实现或 fixtures。
- **诊断与不变量**：自动认证只接受精确认证 origin/路径的唯一明确登录动作；保留文档对象与 session/document/operation、单次密码投递、页面策略和人工挑战边界。兼容性以公开页面结构证据定位，不读取用户页面已有密码或认证资产；自动测试仍仅合成/loopback。公开只读调查与本机合成证据分别记录。
