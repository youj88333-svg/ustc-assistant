## 依据、范围与不变量

依据[07](../../architecture/07-constitution.md)、[08](../../architecture/08-target-architecture.md)、[09](../../architecture/09-contracts.md)、[10](../../architecture/10-runtime.md)、[11](../../architecture/11-component-designs.md)、[12](../../architecture/12-cross-cutting.md)、[13](../../quality/13-risks-and-acceptance.md)、[14](../../reviews/14-overall-review.md)、[15](../../workflow.md)及[文档维护规则](../../maintaining.md)。用户本次目标扩展了原“仅私有交付”的准备范围，不等于已发布，不替代M1非空考试、设备/麦克风/通知等未观察项。

保持五来源、本地日程/任务、Agent、自动认证与只读采集、事务/取消/恢复、个人覆盖和现有隐私授权。正式业务、浏览器认证资料、现有安装及原私有包不触碰；历史及两份归档不重写/删除，不读取实际秘密或要求用户在聊天提供Key/签名密码。审计只针对Git受控内容和公开许可；扫描输出脱敏，不上传私有代码/扫描结果到第三方服务。

准备Windows x64完整便携ZIP，以及Android ARM64与模拟器x86_64候选APK。用户已选择Android独立正式身份cn.ustcassistant.mobile，与此前测试版并存且不自动迁移；不能覆盖/卸载已安装测试版、清数据或沿用调试构建冒充正式版。长期签名私钥由用户本机初始化和保管，不进Git、日志、安装包或公开附件。Windows无既有正式签名凭据时如实标明未签名，不伪称可信发布者。

代码许可限于有权授权的原创部分；模型权重、第三方SDK、图标和学校材料各核实来源及再分发条件，未知项明确列出。保持公开功能边界，不为整理文档移除已验收能力；需要调整资源分发或保留承诺时先给出具体方案。

## 执行约束

全量检查针对实际产品/发布变更执行；纯文档切片只跑文档及差异检查。学校真实认证和模型用量不作为自动发布测试，工程检查只用合成/loopback/临时资产。SDK、依赖、工具和临时文件留在E盘；只保留当前候选与必要小型报告，避免重新累计所有阶段安装包与完整模拟器矩阵。测试虚拟机最多按本切实际需要建立，并在闲置后按固定清单清理。

相关提交可按既有授权正常同步两个远端的维护main，准备分支不擅自镜像所有历史/标签，不强推或改GitHub公开级别。执行结果、失败和具体发布阻碍写[记录](records.md)，用户选择及最后发布确认另写acceptance.md；尚未取得的决定持续待定，经过时间不当作批准。
