# 发布准备的用户决定与保留项

2026-10-25用户要求进行开源准备，最终在校内GitLab Release发布安装包，并先后确认：

- “接受，按Apache-2.0准备”：只覆盖有权授权的原创部分，第三方与来源材料保留原边界。
- “那就采用独立正式版”：Android正式身份`cn.ustcassistant.mobile`，与此前`.qa`测试版并存，不自动迁移资料，不为安装正式版清空或卸载测试版。
- 图标先确认AI生成，随后补充为在学校标识基础上参考网上流行的二创AI形象改编；最初作者和原帖无法核实。该事实不被记录为明确的第三方再授权。
- 用户随后明确“不用可选方案，这个图标版权不用纠结”。据此沿用现有图标，停止替代方案，不将来源追溯作为本次准备的阻塞项；来源事实与代码许可边界照常记录。

- 用户按本机安全初始化命令完成长期Android签名材料生成，并回复“已完成”；公开DER证书及摘要已独立核验，私钥和密码没有发送到聊天。

以上是准备工作的范围/选择和本机签名初始化，不是已公开项目、上传附件或本阶段验收通过。最终源码、安装包/证书/哈希、材料范围与已知问题准备完毕后，再取得具体公开发布确认；当前保留项和工程结果见[记录](records.md)。
