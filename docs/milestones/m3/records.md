## 2026-10-11：校园入口与 Agent 边界

用户指定校园首批来源为教务处[通知新闻](https://www.teach.ustc.edu.cn/category/notice)与[学生事务/服务指南](https://www.teach.ustc.edu.cn/category/service/svc-student)，财务处后续接入。用户提出校园内容应按需检索，由 Agent 根据问题调用工具，要求进一步明确存储与职责边界。

主代理使用公开网页读取工具查看两栏目、通知第二页、站内“成绩单”搜索及两个详情页。未访问用户登录浏览器、认证资产或正式业务记录，未运行产品实现或真实来源自动测试；网页可读只支持以下规划观察，不授予生产契约许可：

| 公开观察 | 对任务的影响 |
|---|---|
| 通知新闻页显示分页至 106；第二页仍包含置顶条目；栏目部分链接指向其他学校站点 | 按需检索及有界分页；处理重复条目，不将栏目全部内容预抓或将外站自动纳入读取许可 |
| 学生事务页包括学习/学籍/考试/成绩等办事主题、FAQ 和多个年份的学习指南 | 不能当成单一时间线；范围含已选主内容入口，具体归属与详情关联须验证 |
| [“成绩单”站内搜索](https://www.teach.ustc.edu.cn/search/%E6%88%90%E7%BB%A9%E5%8D%95)返回学生事务、教学、信息等分类结果，并有分页 | 站内搜索存在不等于已证明栏目过滤；不得把全站结果直接交付为用户指定范围 |
| [成绩单办理 FAQ](https://www.teach.ustc.edu.cn/service/svc-student/13824.html)有网页正文，页首标 2021 年，页尾另有 2026 年时间 | 保留可证的时间字段；额外日期的语义待核实，不仅凭发布时间或年份判断现行适用性 |
| [2026 本科学习指南](https://www.teach.ustc.edu.cn/service/svc-student/20496.html)网页为介绍，提示查看/下载 PDF | 网页读取不等于附件正文读取；附件入口及解析范围须明确，不把未读内容记为已验证 |
