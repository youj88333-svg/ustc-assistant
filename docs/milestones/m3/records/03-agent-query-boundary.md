# 2026-10-11：Agent 公开查询准备与验收入口

## 用户明确的定位

用户明确这一部分不暴露给用户直接使用，也不直接生成 Agent 工具；搜索、读取和知识库最终通过 Agent 暴露给用户。M3 为 Agent 查询公开信息做准备，设计应方便后续创建工具，允许临时界面人工验证。

此说明修订上一版将查询/知识库列为独立用户功能的解释，不改变评课在线、教务/财务精选长期文本、通知排除入库、登录内容跳过和开发期转换的既有决定。具体实施暂停继续有效，不据此恢复代码或材料制作。

## 设计落实与未实现部分

范围及验收以 [唯一任务单](../plan.md)为权威，原因见 [范围决定](../../../decisions/public-text-knowledge.md)。内部能力由 C1/C2/C3 提供；未来 C4 再适配工具、授权和安全结果投影，C5 展示对话与引用。M3 不创建独立产品入口，不注册模型工具或调用模型。

内部契约按 [09 K-07](../../../architecture/09-contracts.md#k-07-公开文本材料与知识库)准备版本化、有界检索与按引用读取、来源/时间/定位、覆盖及失败状态。临时验证界面只消费同一接口，不持有抓取/索引规则；移除后不影响核心能力或契约测试。材料载入/清理与只读查询分开，不成为未来 Agent 查询的隐式写操作。

本轮只修订现行设计、决定、计划、导航和本记录，没有新站点探索、材料转换、业务代码/数据库修改或验证界面创建。接口字段、生产 HTTP、完整首批目录、中文索引及工具/模型链路均未因文档修订变成通过。M3 未验收或关闭，恢复实施等待用户后续指令。
