# 2026-10-11：三站调研、文本材料与校园直连

本轮是范围讨论阶段的真实公开研究，产品实现未开始。主代理 GPT-6.1 Sol / max；教务与财务分别由 GPT-6 Luna / max 做限定只读探索，主代理独立核对具体页面和材料。未读学校登录资产或正式业务记录，未执行报名、提交、下载管理或模型调用。已有 M0/M1/M2 验收保留。

## 范围变化

用户将财务处纳入本期，明确 M3 不带 Agent、需要登录才能读取的信息跳过；初始要求附件只给链接。随后根据 PDF/图示观察提出必要文件/图片入库，选择“教务、财务精选资料入库；评课在线查询”，并要求统一文本。最后补充校园 IP 限制时绕过 7897 代理直连。

现行决定见 [校园文本知识库](../../../decisions/public-text-knowledge.md)，唯一任务单见 [M3](../plan.md)。初始提议和当时观察仍留在 [原记录](../records.md)，不覆盖为当前方案，也不把本轮研究算作实施/验收。

## 一次性提取可行性实证

全部材料来自选定公开页关联地址；Conda basic310 的 stdlib HTTP 和 pdfplumber、Windows PowerShell 5.1 的系统 OCR 仅用于研究。PDF 视觉核对使用捆绑 Poppler 渲染和本地图片查看；原生产品不采用 Python/PowerShell CLI 作为运行实现。公开原件与渲染图放单独临时目录，未加入仓库。

| 材料 | 实际读取/样本核对 | 能证明与不能证明 |
|---|---|---|
| 2026 本科学习指南 PDF | 28,981,817 字节，62 个物理页；抽看 1/2/10 页文本分别 72/505/1402 字符；第 10 个 PDF 页视觉为印刷第 5/6 页的双页布局，含多栏与表格 | PDF 可公开获取且部分有文本层；并未验完全部 62 页，不能记全书提取或阅读顺序已正确 |
| 缓考流程图 | 372,818 字节，790×1155；系统中文 OCR 成功，59 行、567 紧凑字符、537 个带位置的词 | 图示文字可本地识别；线性 OCR 次序不能表达学生/院系/教务处三泳道及条件箭头，需要结构校核 |
| 财务报销指南 PDF | 6,010,625 字节，38 页；第 1 页零文本/一图，第 2 页有文本，第 3 页零文本/零图/零向量，渲染确认真空白；第 4–6 页有文本 | 需按页区分图片封面、文本和真空白，不把零文本统一当失败，也未验证全文语义 |
| 财务高频业务网页 | 主内容 2128 字符、一张 HTML 表格 | 公开正文及表关系存在，不以导航/全页图片数量推断内容形式 |

原生 OCR 识别语言实测含 zh-Hans-CN、en-US。系统 API 的位置可用，但没有本轮可用的逐词置信度分数；原生实现不能虚构阈值。PDF 文本层、表格/阅读顺序和 OCR 图示关系是不同质量问题，统一存文本不能抹去必要结构。

## 失败、纠正与实际边界

- 沙箱默认网络访问本机代理被拒；本轮具体公开只读请求经工具审批后执行，未改全局网络或读取认证信息。这是工具环境限制，不记为产品站点失败。
- 评课的一次性 HTTP 试探出现 TLS EOF，浏览器正常；直接 HTTP 路线仍待产品验证，未关闭证书校验或增加生产浏览器后备。
- 财务搜索的最小 POST 试探为 403，浏览器原生表单可用；公开上下文字段及分页继续待核，不预设自由查询 API。
- 财务 PDF 的普通 HEAD 403，带已核对公开文章 Referer 的 GET 成功。没有使用 Cookie/Token；HEAD 失败不作为不存在证明。
- 初步调研根据全页图片数将报销正文误判为四张图片；主代理随后核对内容区和实际 viewer，纠正为嵌入 PDF。原观察与纠正分别保留，不能以页面计数或子代理结论替代实证。
- OCR 的 PowerShell 7 WinRT 加载及 StorageFile 路径入口失败；Windows PowerShell 5.1 配合本地 .NET 文件流转换后成功。此结果仅证明研究可行，不证明产品 C++/Dart 端口、取消或资源预算。
- 浏览器一次动作超时导致控制运行时重置，但实际搜索已打开新标签页；通过清单找到结果页后续核对，未把控制超时记为站点失败。用户误关评课标签后重新打开，亦未记来源不可用。

## 校园 IP 提示与本机直连复核

财务子代理此前访问“学生活动经费报销”得到校内 IP 限制提示。用户说明本机在校园网，授权单请求绕过 7897；主代理随后用 ProxyHandler({}) 只对该公开请求直连，保留环境变量及 TLS。

最初代理/直连两次试探均停在旧 .htm 的 301，还没有读取正文。核对 Location 后确定它指向同站 **HTTP** .psp，未跟随；另请求实际 HTTPS .psp。两路线本轮均为 200，主内容区各 587 字符、无 IP/登录提示，内容与报销主题匹配。这证明本机直连可读；因本轮代理也可读，**没有证据断定此前受限仅由代理导致**，更不能宣称永久可达。

当前规则是明确校园 IP 提示时按授权直连复验，普通 403/超时不误判；登录限制仍跳过，HTTPS 别名须有具体来源证据。对该页的原受限、301 停止和新成功分别记录，不能把失败改写为通过。

## MinerU 单页试验与两份文稿

主代理读取用户外部 mineru-convert 和它要求的 document-visual-reading 技能，适配文件读取/视觉工具，不修改技能或其他代理软件。既有 CLI v0.5.9 和配置存在；只查存在布尔值，不读取或显示 Token。相关缓存未命中；经技能的进程级直连包装预检 CDN 为 403（TLS 可达，不等于结果下载成功），上传这份公开学习指南并仅解析物理第 10 页，pipeline/ch/Markdown，一次提交。未上传学生业务或浏览器资产。

实际下载输出为 3289 字节 Markdown 和三张图；读取后发现只含左页三张 HTML 表格，多专业串成一词，右页课程说明未进入可检索正文。主代理已看完整原页，交 Luna / max 补写受限 Markdown，并对照原图核对；不能以 CLI Done 或“Parsing 0/1”进度文字推断整页/整书成功。读取产物时沙箱临时路径映射曾找不到文件，改用已经核对的实际绝对路径读取，没有重提交转换。

两项均沿用 GPT-6 Luna / max，互不扩展应用代码：

- [缓考流程](../../../../knowledge/curated/teach/deferred-exam.md)：Luna 对照完整原图描述三方角色、审批分支、补考条件及提示；Sol 复核并将原图“教学秘书审核签字”和“校医院负责医生”明确核对。图示描述已核对，未验证现行政策有效性或应用导入。
- [手册单页样稿](../../../../knowledge/samples/teach-handbook-p10.md)：补齐右页课程说明/要求，左页合并专业按共享组表达；Sol 核对该物理页并纠正一次把“立德树人”误连成必修课名称的文字。只覆盖物理第 10 页、印刷 05–06，不作为完整手册材料。

两个 Markdown 文稿保留在 [制作目录](../../../../knowledge/README.md)。研究公开原件、渲染图和 MinerU 临时输出所在的唯一任务目录已核验并清理：9 个文件、36,084,994 字节，删除后目录不存在；没有清理既有转换缓存、工具配置或应用资产。

## 根实际检查

为覆盖新增知识文稿，现有文档检查器沿用同一链接/锚点与 reparse 拒绝逻辑扫描 knowledge。根运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/check-docs.ps1`：退出 0，73 个 Markdown、552 个本地链接、冻结档案 manifest 核验通过。根独立 `git diff --check` 退出 0，仅原有 LF/CRLF 提示；新增文稿/参考末尾空白检索无命中。一次多文件补丁因整页替换或上下文顺序不匹配被拒，读取当前内容后按明确替换修复，没有覆盖用户/其他代理修改。

本轮修改设计/来源/记录/状态、制作文稿和文档检查覆盖；未修改 app/ 业务代码、正式库、学校密码、分区、共享转换工具或其他 worktree，未执行提交/推送。应用实现、完整资料目录及真人验收继续待 M3.1 后续。
