## 已装配实现与校核

内部契约为 public-query-v1 / knowledge-edition-v1。在线 C2 共用 JW/Young 的全局租约，每作业匿名 HTTP 客户端、逐跳和最终请求意图复验，受控引用/游标保留 10 分钟；失败取消与真实收口恢复分开。C3 在现有 SQLite 的 schema 5 中增量建立公开状态、Markdown/片段/索引、批次目标/回执和安全审计，不制造学校账户、不读取正式业务事实。资料维护独立于网络租约，清库有单独 epoch 和即时维护世代。

7 项校核稿已逐项记录选定范围与排除、来源日期/版本、原件与校核稿摘要。Sol 核对三张完整流程图和四篇公开 HTML 的关键事实，修正调整流程的正选阶段、原则上不允许一年级拟转专业缓修，以及放弃流程原图摘要错误。正文仅从清单指定小节编译，元数据/制作记录不进入正文；必要版本、人群、选定范围、质量及未知现行性在 Evidence 单独投影。两份长 PDF 和单页样稿不在首批。

临时面板仅调用同一内部端口，普通构建 USTC_M3_VALIDATION 默认关闭；验收构建显式启用。不装配模型 SDK、工具注册、原件下载、OCR、MinerU 或转换脚本，Markdown 不自动加载远程图片。

## 发现、修复和反例

Astra 两次只读复核，Sol 修复并用故障注入验证：同一材料重复提交不能伪报整版完成；目标修订绑定不可改写；COMMIT 失败时 SQL 与内存计数/活动能力均不提前成功；长单节有绑定参数的正文续读；大重定向响应体同样执行解压后 2 MiB 限额；版本/人群/范围/质量不在证据投影中丢失。第二轮还修复排队准入与清库竞争、并发恢复可能取消新租约、同站跳转改变 q/term/sort 的意图，以及长点评尾段错误宣称完整。子代理声明没有替代根执行。

正式 Dart 手工观测暴露并修复合成样例遗漏：评课固定 noredirect=True 防止无课程时转入点评搜索，课程空态为 span 节点；分页空 term 规范化但不能改关键词；学期选项的精确 #review-anchor 去除，评分/排序选项不混入学期目录；财务 li.news 的 n1–n14 均读取，终页 void 占位需明确页码证明，已验证 htm→同路径 psp 别名一律改为 HTTPS 再请求；教务 sticky 公告在关键词空态排除。表格额外验证 rowspan/colspan 的有界展开，保留列和单位/条件的关联。

财务常见问题是公开留言标题列表；本轮内置浏览器只读点击一条及“更多”，两个公开回复入口均返回 404。正式能力因此保持 unavailable，不把问题标题当官方答案，也不转入留言/登录；临时标签均关闭。财务原生 POST 关键词仍未建立固定生产契约，保持 unavailable。
