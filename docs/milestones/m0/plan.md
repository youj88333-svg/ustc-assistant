#### 本切最小实现契约与文件归属

| 归属 | 本切接口与行为 | 写入者 |
|---|---|---|
| C0；`app/lib/core` | UTC 时钟与显式北京时间展示；固定错误码；`JobStamp` 绑定合成本地上下文、来源/契约、job、generation/epoch；目录所有权能力，不包含平台句柄或学校身份 | Sol 主代理 |
| C1；`app/lib/source` | 纯合成来源；当周北京时间范围、稳定外部身份及三条假事件；完整空快照合法，不完整/来源失败不封存；深度只读集合和内容指纹，正常关闭不撤销封存产物；首次收口失败可重试 | Luna / max；共享接口由主代理先定义 |
| C3；`app/lib/data` | Drift 事务及参数化 SQL 的全新 demo Schema；局部元数据、作业、事件、导入回执、安全计数审计、演示汇总待办；不建正式账号/秘密/会话表。导入在同事务复验上下文/版本/维护、完整性、范围、唯一 ID 和指纹；稳定外部身份 upsert 保留本地 ID，缺失标示但不删除 | Sol 主代理 |
| C2；`app/lib/jobs` | 唯一入口同步取得全局租约，映射 C1 产物到 C3 导入契约；关闭后才导入；取消和导入进入同一事务队列，以先后裁决，提交后保持 committed；收口失败持租约并恢复，未收口不能发新作业 | Sol 主代理 |
| P；`app/lib/platform` | Windows 目录的真实排他句柄，路径别名归一并拒绝 reparse；先持有所有权才创建/打开 demo 数据库；退出/失败先排空数据库再释放，第二实例拒绝；默认仅用独立临时目录 `ustc_assistant_m0_demo_v1` | Sol 子代理；不得复用旧实验源码 |
| C5；`app/lib/app` | 明确“合成演示”，展示日期/记录与提交、重放、失败、取消和待办；所有内部账号/作业/操作身份不进状态文案；通过既定端口控制，不直接操作库或来源 | Luna / max；`main.dart` 与组合根由主代理 |
| C4 边界 | 界面声明真实来源及 Agent 尚未接入，M0 无学校/模型联网及浏览器装配，不伪造可用工具 | C5 展示，主代理检查 |

本切普通采集每次生成新的导入操作身份。专门的“重复上一导入”只重放上一已提交的不可变规范化载荷及操作身份，在新有效作业上下文中返回既有回执，不把相同内容的未来观察误当同一操作；同操作改内容稳定拒绝。不完整输入不影响旧记录，完整空快照只标示本范围内来源缺失。

C3 的业务、回执、审计和演示汇总待办一次提交；汇总在事务外完成，失败保留已提交事实及持久 pending，重启显示并可重试，不宣称实际提醒已实现。启动使遗留未提交作业失效，保留提交与待办；SQL 注入失败和实际进程退出分别验证回滚/提交持久性。维护测试以 epoch/屏障拒绝旧结果，不对旧工程或真实资产执行 reset。

验证包括真实双进程排他/退出后重取、别名/junction 拒绝、正常/空/不完整来源、忙时拒绝、封存后正常关闭、取消与提交两种次序、旧版本/维护拒绝、同操作重放及内容冲突、实际 SQL 回滚、进程退出后的回滚/提交恢复、待办恢复和界面用户路径。主代理检查模块依赖与真实服务未装配；命令、结果和人工未验项在本任务下追加，不再建立另一份计划或施工报告。
