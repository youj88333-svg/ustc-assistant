# Windows 收尾与1.00版本决定

## 1.00 私有基线认可（2026-10-15）

用户原话：“windows端可以作为1.00版发布了，虽然可能还有bug，但是需要正式用户使用才能发现”“先不公开发布，做一些收尾工作”。据此记录Windows收尾的整体使用判断已获认可，版本显示1.00、工程版本1.0.0+1；本次仅本地准备私有包，不等于公开发布授权。

本轮版本一致性、完整运行资产/许可与摘要、本地构建及相关根检查现已完成，实际结果见[1.00收尾记录](records/05-windows-v1-private-release.md)。该认可不补造逐项真人验收、业务计数或新来源样本，不把语音、非空考试、真实调休/撤回、通知睡眠/重启等保留项记为通过；[已知问题](../../releases/windows-1.00-known-issues.md)随私有包提供。

用户另确认“优先 Android APK，兼顾可安装 APK 的鸿蒙”。本轮只做[迁移调研](../../research/android-apk-migration.md)，不据此开始移动端实现、改变Windows资料格式或迁移凭据。
