## 界面风格与信息层级

采用安静、清晰的工具型界面：白色内容画布、浅中性导航底色、深色正文，沿用学校深绿作为操作和选中重点。以字号、间距、分隔线区分章节；阴影、渐变和大面积染色不承担层级。普通内容至多一个平面章节，不再一层页面卡片包多张卡片。用户消息、当前审批、错误及弹层可以有必要的边界。

间距以 4/8/12/16/24 为主；常规输入框和按钮圆角 8，弹层 12。正文维持清晰字号和行距，辅助文字仍需可读。沿用本地系统字体与当前浅色主题，不增加暗色主题功能。手机交互目标不小于 48dp；桌面保留鼠标、键盘、焦点与提示。装饰动画不增加等待，服从系统减少动画设置。

统一视觉值由 `app/lib/app/app_design.dart` 提供，`productTheme` 负责全局主题。共享 `WorkspaceSection` 是透明章节与可选分隔线，不能替代成另一种巨型卡片；业务 Widget 继续通过原有 Port/Controller 装配。

## 布局与内部接口契约

### 应用壳

默认页仍为 Agent，日程是另一主页面，任务归日程；设置为辅助入口。Windows 使用更窄导航栏，空间不足时使用图标栏/抽屉；手机保留两个底部目的地和设置入口。按实际可用宽度选择布局，不按设备型号猜测。保持 `IndexedStack`、`WorkspaceVisibility`、返回键、输入焦点、键盘和后台暂停语义。

Agent 正文和设置表单限制阅读宽度，日程画布使用可用空间；横屏、桌面窗口变化和手机键盘出现时均可重新布局。手机不靠横向滚动阅读普通对话/表单。底部导航不抢占键盘展开时的高度。

### Agent 与晨报

- 移除对话区的外层大卡片和每条助手回复的整块底色；回复正文靠排版组织，用户消息保留轻量区分，图片和 Markdown 仍可读。
- 过程、引用、历史审批与模型返回的独立思考默认按原规则折叠。当前审批保持输入区旁的明确入口及手机自动弹层，不能被折进不可见历史。审批 ID、版本、记住授权、提交/拒绝、过期检查完全保留。
- 输入区保留图片、麦克风、发送/停止、`/compact`、`/clear` 和错误导出。输入框只需一层边界；大字号、键盘和短横屏时允许局部滚动，关键操作必须可达。
- 晨报入口是一行状态；阅读面板用重点摘要、时间列表和细分隔，保留隐藏/恢复、重试、来源覆盖和原文跳转，不改变生成职责及后台调度。

### 日程与任务

- 日期/视图/操作工具栏紧凑呈现，筛选和次要动作按需展开。周表是画面重点，手机正常字号能看整周；极大字号可采用明确的最小列宽回退，不能把文字无限压小。
- 保留教学节次轴、凌晨压缩、同名同色、教室优先、红色圈叹号冲突提示、全天不参与时间重叠、任务截止栏黄/红警示。来源失效、隐藏和不参加的投影规则不变。
- 详情以标题、要点和行式编辑组成，减少嵌套卡片。个人安排创建/重复/移动/撤销、备注、出勤与听讲计划、任务本体和时间块独立状态、日期时间选择器、两槽提醒及提醒范围原样保留。

### 设置与维护

- 来源、Agent、晨报提醒、显示、数据与隐私、关于六区保留；分区导航采用平面文字选项，手机可以滚动分区导航，表单本体不得横向滚动。
- 来源状态/共享凭据说明简短呈现；教务、二课切换和自动同步/取消/恢复仍清晰可达。普通设置使用标题和分隔线，不逐层套大卡片。
- 日常项优先，详细能力或维护说明可以展开；错误、待恢复、保存结果和破坏性维护后果不可隐藏。日志导出及危险动作的原有确认机制保留。
- 所有异步保存、epoch/generation、并发编辑防护和恢复状态由原 Controller 裁决；重排控件不能放松校验、静默保存或丢弃草稿。

## 验收条件

1. 手机 320/360/412 宽、短横屏、键盘展开与安全区下，主要正文和表单无溢出，输入、当前审批和提交可达；文字缩放 1/1.5/2 下可滚动阅读，不以固定小高度截断重要内容。
2. Windows 1024×768、1280×800、1440×900 下导航、对话宽度和日程画布合理；缩放/窗口变化不丢状态，键盘焦点及返回逻辑保留。
3. 合成场景覆盖带引用/思考/当前审批的 Agent、带地点/冲突/全天项/任务的周表、任务详情、来源错误与恢复、提醒设置、晨报阅读。根查看实际渲染图，不能以无异常的空页面替代审查。
4. 既有功能测试继续有效；新增测试验证关键可达性、信息优先级与响应式行为，不测试装饰实现细节。相关修改逐切检查；交付前根运行 analyze、全套 Dart、相关 Windows 原生/Android 合成集成、构建/lint/文档检查。
5. 不迁移/清除正式业务数据、不读真实数据库或秘密、不触发学校/模型请求。构建出独立 Windows 暂存版与同签名递增 Android QA，不覆盖 Windows1.00 或旧 QA 证据，不擅自操作 MuMu。
6. 自动验证、图像复核和用户实际体验分开登记。无目标手机，不能宣称手机/鸿蒙、真实学校/声音/通知已通过；本轮最终体验由用户反馈，不提前记作关闭。
