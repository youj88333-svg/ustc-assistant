## 最终统一体验清单（待验）

用户方便时集中体验以下内容，一次反馈结果或异常操作即可；不重复故障矩阵、不要求清空正式业务或完全重置。

1. **对话与查询**：问“明天有哪些课”，核对北京时间、教室/教师和本地日程一致；确认气泡无“你”，步骤/出处默认折叠且可展开。另问一个普通问题试停止，附一张非敏感图片看所选模型是否理解。
2. **公开资料与出处**：问一项缓考/证明/报销流程及一个课程/教师，展开出处与片段，判断版本、覆盖和未知适用性说明是否可理解；不可用查询不能假报无信息。
3. **本地行动与规划**：让 Agent 创建名为“M5 验收任务”的测试任务并安排两个时间块，先拒绝一次确认零改，再重新提案批准；检查任务和块分别显示，尝试移动或整组撤销，确认冲突/截止提示及日程衔接。可从日程/任务“交给 Agent 讨论”，核对只预填、需自行发送。
4. **来源与连续使用**：明确请求刷新一个既有学校来源，核对卡上的学期/日期及许可后执行，确认原自动认证/学校挑战/继续链路自然衔接。正常退出重启，查看持续聊天和真实提交卡，确认不自动重跑。发送 `/compact` 确认聊天仍可见，再在方便清聊天时发送 `/clear`，确认业务和设置保留；不要求删除正式业务。
5. **参数修复与反馈**：重试原“下周二交作业，请帮我下周一安排一个小时”同类请求，核对中文回复及具体可批准任务/时间块卡；在“设置 → 数据与隐私 → 运行诊断”导出一次最近日志，确认保存入口易找到。若有错误可从错误处导出，无需发送私人问答或日程原文。

6. **最新反馈修订**：重试“今天下午的课不想去了”，确认与日程一致并能修改本地出勤计划；已有许可时仍正确显示实际结果。第一次所需批准可勾选记住，在设置看到并能撤销。确认完成审批可折叠，日历任务栏与黄/红截止提示合理；重试几秒中文听写，判断实际文字是否正确并试取消。只反馈体验或异常，不要求提供录音、备注、账号和日程原文。

7. **§23 上下文与许可修订**（待 M5.9 工程完成后）：延续一段包含候选选择的对话并按“第二个/继续”完成查询或出卡；跨日理解原消息时间，目标变化时不静默替换。审阅并分别主动启用私人内容读取、17 类日常操作包；检查说明易懂、按任务读取而非整库预载、设置可撤销。仅建议模式可展示提案但不得提交；未授权时只出现一次具体卡，有许可时准确显示实际回执。明确卡片自然确认只作用于当前卡、改条件后需新卡。无需把私人字段或问答原文发送到聊天反馈。

学校额外挑战仍由用户在学校窗口完成，Key/密码只在应用主动提供；无需把账号、日程明细或问答原文发到聊天。遇到异常只说明操作/现象，必要时提供应用安全摘要。普通聊天/真实问答/视觉/规划质量/Agent 发起来源刷新、§23 新实现与最终关闭全部保持待验，不用此前 toolReady 或合成脚本结果代替。

M1 非空考试、Young 独立报名状态/未观察样本、财务在线关键词/FAQ、政策现行性及完整 V 项继续按既有登记保留。M5 关闭仍需用户集中体验后明确确认；本轮没有补造该确认。
