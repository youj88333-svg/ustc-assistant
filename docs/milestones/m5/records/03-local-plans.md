# M5.3 本地方案、批准与整组撤销

实施日期：2026-10-13。依据 [M5 唯一任务单](../plan.md) §6–10/17、[07](../../../architecture/07-constitution.md)至 [12](../../../architecture/12-cross-cutting.md)、[13 验证登记](../../../quality/13-risks-and-acceptance.md)、[14 审查方法](../../../reviews/14-overall-review.md)和 [工作流](../../../workflow.md)。真实 toolReady 已满足依赖；用户批准持续工程、最后统一真人验收，见 [批准记录](../acceptance.md)。本切工程授权不替代应用中的具体业务批准。

## 分工与实现

Sol / max 持有共享契约、C3 批事务/迁移/撤销、C4 等待和预算、组合根及批准卡集成。Luna / max 承接固定动作工具适配、空闲纯服务、互不重叠的合成测试和紧凑对话页面；跨文件的最终衔接由根完成。Astra / high 按具体风险复核，根修复并复验。

新增 `AgentLocalPlanPort`、不可变变化/patch、计划内新任务短键依赖、C3 签发的批准对象及稳定回执。propose_local_changes 只能准备，不提交；propose_undo 只产生当前整组撤销卡，propose_planning_preferences 只准备显式偏好。模型参数没有批准、SQL、owner 或业务 ID 权限。卡片列实际改变的名称、北京时间、地点、重复作用域、依赖和警告；未修改的私人字段原样保留，不出现在卡摘要或模型结果。

C3 schema 12→13 增量增加动作、计划回执/审计和显式偏好，保留原配置、日程、任务、知识、秘密与已有 Undo。先核验所有原引用和窗口修订，再在同一事务处理最多 20 项、同任务多个块的聚合版本及计划内依赖。成功一次推进 agenda_revision、一次方案审计/回执，写入一个整组 Undo；任意目标失效、校验或最终检查失败整体回滚。内部单步业务体不制造多个对外回执和撤销槽。

批准对象由 C3 按具体方案签发；旧卡、跨运行、跨维护、改内容及重复按钮不能增加写入。同一已提交操作可从稳定回执对账。停止先同步作废内存许可，再等待异步事务和资源排空；提交前停止零写，提交后停止保留已提交事实，回答/历史保存失败不回滚业务。

整组 Undo 复用原最近一次/24 小时槽，新增有界 v2 逆操作，旧 v1 保持可读。生成前保守检查 48 KiB，最终整组上限 64 KiB；逆序重核真实目标/聚合版本和关系对，任何后续修改冲突则整体拒绝。删除单个块不连带删除其他块；删除父任务后再操作其块拒绝。撤销不是整库回退，也不改变学校事实。

C4 等待当前卡时暂停主动执行计时；拒绝/重复旧决定零写。批准后的变化丢弃旧工具读结果，重建引用并保留当前提交回执，允许重新读取相同参数；累计请求/工具预算不重置。待批准/失败/提交卡直接显示，步骤和出处默认折叠，用户气泡去掉“你”。

## 根核验与裁决

合成测试使用临时/内存库、脚本化网关及明确 C3/Calendar 契约，不访问正式业务或学校。核心用例包括：新任务＋两个依赖块、已有任务多块、原子故障/停止回滚、目标/窗口变更、部分 patch 与私人字段保留、关系删除再建、预算超限、同操作对账、整组撤销和后续修改守卫。

- 根早期定向适配/运行/UI 81 项通过；分段检查发现一项历史整理说明与旧测试前缀不一致，修正断言只读取整理条目并保留覆盖说明。
- 预览先前按“合并基线”构造修改，可能改变部分 patch 的实际冲突区间。Astra 指出反例后，根改为直接使用实际 patch，并把窗口外修改目标纳入预览，新增对照检查。
- 无限重复整组只能报告部分覆盖；单次例外只修改指定窗口。根修订错误地要求单次例外承担整个无限系列覆盖的测试，保留整组硬性空闲拒绝和未知范围提示。
- 根发现最终异步检查后到提交前的撤销间隙，增加同步许可复验；任务截止在 requireFree 准备和提交都核验，手动非空闲方案明确晚于截止的警告，估时未安排完整时提示剩余。
- 相关最终约束批次 49 项通过；最新全套与原生批准/撤销/重启结果统一见 [M5.5/M5.6 收口记录](05-continuity-and-delivery.md)。不把子代理通过当根验收，也不以单测数量替代上述行为证据。
