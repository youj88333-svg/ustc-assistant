# M5.4 时间规划与固定来源协调

实施日期：2026-10-13。依据 [M5 任务单](../plan.md) §6–10/17、[07](../../../architecture/07-constitution.md)至 [12](../../../architecture/12-cross-cutting.md)、[13](../../../quality/13-risks-and-acceptance.md)和 [工作流](../../../workflow.md)，依赖 M5.3 的当前卡批准与用户真实 toolReady。复用已批准 M1/M2 的认证、单账号、北京时间、分区/许可及租约；不改变学校只读范围，不读取实际密码、响应或正式记录。

## 规划服务

Luna / max 按根契约实现纯 `agent_free_slots`，Sol / max 负责 C3/C4 交接和最终提交守卫。find_free_slots 读取与日程页相同的当前窗口，在最多 31 个北京日期内按显式工作日/时段/时长/休息/截止与过滤找候选，最多 20 项；日期和占用使用半开区间，跨午夜、重复例外、来源缺失和任务块均按现行投影。

全天不占定时空闲；隐藏/跳过依显式选项，已标“不冲突”的活动仍占实际时间。范围/输出超限和未知覆盖分别说明，不把有限查询称为完整长期规划。规划本身不写入；具体时间块经卡批准后，C3 复验真实窗口、所有目标、截止及所使用的偏好修订。硬约束不成立整体拒绝，不通过修改旧活动或降低要求完成。

用户可在 Agent 设置显式保存规划偏好；模型只能 propose_planning_preferences，当前卡确认后更新版本。普通对话或有限历史整理不自动形成个人画像。

## 来源契约与装配

固定 3 个函数为 query_source_options、request_source_refresh、query_young_activities。前两者只选择 JW/Young Calendar 和受控目录/北京日期，不接 URL/SQL/账号/密码。query_source_options 按最多 10 个学期分页、短期引用映射和目录签名守卫，并单独给出上次成功学期，避免真实 81 项目录超出单结果预算。人类明确要求刷新才开放相关工具；准备具体来源/学期或日期卡，应用批准后才启动同步。

`AgentSourceCoordinator` 持有专属 JW/Young C2 实例；手工来源仅共享同一 C3 和 WorkLeasePool。准入用实际 C3 票据绑定当前 Agent 动作，不接受模型造批准。导入事务同步写业务、agenda_revision、真实来源回执和动作已提交事实。自动登录复用既有受保护学校密码、已记学期及固定业务核验，学校挑战等待/继续与既有可见窗口衔接。取消、重试 recovery 和关闭只影响专属实例，不借用手工作业。

query_young_activities 是明确请求的只读活动目录，不需刷新卡，不导入个人日程，不执行报名/退选。最多交付 20 项安全标题、地点、活动与报名时间，给实际总数/截断及 registration_verified=false；不会推断本人报名成功。个人日历同步仍只接受活动关联记录。

`AgentSourceDeliveryPort` 把已交付活动结果绑定实际 Young 票据/回执。C3 在每次模型异步交接后复验 Agent 运行、来源世代和许可；新来源作业或清登录资料使旧结果过期。成功变更丢弃旧模型工具上下文时，清除相应只读引用，已提交回执保留为历史事实。

## 故障修复与证据

- 独立复核指出来源作业进入 recovery 后 `_run` 已清句柄，普通取消可能漏掉残留专属驱动。根按驱动状态排空并 retryRecovery，不触碰手工通道，合成 busy/恢复后再执行用例通过。
- 二课/Young/青春科大的人类范围识别统一，防止模型请求已被开放但动作适配又拒绝相同意图。目录引用分页稳定，同名/未指定学期只允许实际保存默认，不从模型猜学期 ID。
- 根补实际 C2 准入抛出的 AppFailure.busy 映射、staleResult/取消稳定码，不伪报存储失败或复用前次成功。
- 收口独立复核发现：活动查询已提交，首次交付收口失败后第二次回 idle，committed 仍真但活动列表未交付。旧适配因 committed 丢弃 failure，可能误报完整空。根保留失败/回执，将完整性与已交付数量分别判断；总数 0/3 的合成失败均不得报告 empty，原业务不反转。
- 根来源复验/事务/工具/C4 定向批次 49 项通过；后续交付失败修复已纳入最终全套 969 项通过、1 项平台分支跳过。新用例确认来源许可撤销后出站拒旧、已提交事实保留；最终原生与发布结果见 [收口记录](05-continuity-and-delivery.md)。

全部自动来源使用合成驱动、nonce TEMP 或 loopback，不访问学校，不检查正式业务或秘密。真实 Agent 发起学校同步、学校额外挑战及所选模型的规划语义留到统一人工体验；既有 M1/M2 的验收、非空考试后补和 Young 未观察项不改变。
