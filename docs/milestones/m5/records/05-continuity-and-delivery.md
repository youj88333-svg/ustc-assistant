## 连续性与界面

Sol / max 集成 C3/C4 历史、维护、运行状态和本地导航；Luna / max 承接已定 UI 和有界上下文/连续性合成任务，接口歧义与最终恢复由根处理。

历史按页向前读取并去重，不把旧工具结果当当前证据。模型上下文只保留相邻、完整、安全且无步骤/动作/证据/图片的普通对话对；最近至多 6 对/8000 字符，更早只整理人类问题，至多 12 条/2000 字符，明确有限覆盖。失败、中断、旧活引用和业务回答不穿插重放；偏好仅显式版本化保存。

Agent 历史保存动作状态与提交概要，重启不恢复批准、不自动发网或重做写入。清历史、Key、知识、业务和 reset 采用既有世代/维护矩阵；清业务删除对应业务回执/审计，保留明确的历史和模型/偏好，reset 删除它们并保持世代单调。已提交后的回答失败保留提交事实，旧成功卡是历史，不能证明当前业务仍存在。

“交给 Agent 讨论”从日程/任务详情传类型化本地选择，仅预填不自动发送，发送时重新验证目标、窗口和当前权限。显式只查公开资料会撤销预选本地范围。证据返回日程/任务先 C3 核验，再加载目标日期/任务栏目；导航定位只存本地历史，不序列化到模型工具数据。选择在加载后一次消费，普通重建不会把用户切换的栏目强行拉回；reset 清掉旧目标并恢复默认 Agent 页。

去掉用户气泡“你”，每条回答的查询步骤/出处默认收进一个紧凑折叠区；批准、失败和已提交事实直接显示。展开后保留覆盖、日期、出处和片段。使用 safeMarkdown，未验证引用不伪装可信链接。

安全摘要新增实际模型/工具/图片计数、最近运行主动/人工等待毫秒和可用 usage；缺 token/计费字段保持 null/unknown，不估算费用或声称节省。批准与学校等待不耗主动预算，模型/工具累计上限保持不变。已保存模型与能力在应用配置中固定，替换仍须验核；根未读取实际模型 ID、Key 或个人问答。

## 中断检查、失败与修复

用户明确要求检查中断是否留下问题。根核对 Git、代理状态、未提交文件和相关集成契约，保留已保存改动并完成接续，未重置仓库或改动其他 worktree。

- 一条 Luna 页面/导航子任务以 `Selected model is at capacity` 中止，留下已保存 UI/测试。根接管；最终全套初跑为 959 通过、1 跳过、2 失败：一项点击位于滚动区外未等待到可见，另一项把真正的新任务导航当重复重建。根按实际导航意图和可见点击修复测试，并保留“用户切换后普通重建不抢回”的断言。相关 UI/预览/导航批次 54 项通过。
- 首次 Windows Agent 五组为 3 通过、2 失败。实际 reset 后外部页选择器保留设置页，根改为新世代恢复 Agent；另一个原生测试沿用“证据始终展开”的旧期待，改为核对默认折叠后实际展开。
- 修复后的原生批次在第四场景持续无输出约八分钟。本轮只对精确 Debug 路径、该场景 DartVM 父命令和根启动 PID 做守卫检查；最初父进程名校验不符时没有杀进程，确认实际 SDK dartvm 后终止自己的隔离测试，不关闭正式应用。加入临时固定阶段标记后单场景通过，移除标记后正常五组通过；没有证据确定一个可复现产品根因，也不把停滞批次改记成功。
- Astra 复核指出 recovery 漏排空、重复查询误判、部分 patch 预览和提交前撤销间隙等反例，根修复与补测，细节见 [本地方案](03-local-plans.md)和 [规划/来源](04-planning-and-sources.md)。收口再次定向复核确认源结果世代/出站链，并指出“提交后交付失败被报空”问题；修复纳入最终全套。
- 分析末轮曾有新守卫的括号与未用导入提示，根修正后最终为无问题。临时阶段打印、定位标记和测试入口未进入正式默认构建；自动日志留在忽略的 build/。

这些证据说明已接管并修复实际留下的集成问题，不证明此前每次对话中断都是同一原因；本轮不检查正式业务库来推断其状态。
