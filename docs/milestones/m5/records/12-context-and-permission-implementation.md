# M5.9 上下文与执行权限：实施与工程验证

日期：2026-10-14。本文记录用户对 M5 §23 的实施批准、实现、独立复核和根实际检查；唯一任务单仍为 §23。工程证据与真实模型/用户体验分别记录，M5 尚未关闭。

## 用户决定

用户审阅现状、调研和完整修复计划后批准 M5 §23，并要求“开始修复吧”。此前确认后续接失去具体目标的真实失败仍然成立；批准修复不覆盖原失败，也不等于用户体验验收。

## 冻结规格

- 保持一个持久主对话；安全上下文保留人类原请求、助手/工具完整配对、必要工具投影、各消息北京时间收到时间及历史事实的观察时间。历史结果可回答历史问题；问当前状态或准备变更时才读取当前事实。
- 当前配置向模型稳定提供 19 个固定工具，不按问题关键词过滤。跨轮目标别名仅用于定位；应用在每次读取、准备和提交时解析当前目标，并核验版本和已确定的范围。别名不授予权限、批准或目标替换。
- 私人日程备注、任务正文/描述的按需读取须用户在应用内单独 opt-in 并知晓出站说明；读取范围按当前任务有界，默认列表不带私人字段。撤销后受影响结果及其助手/摘要派生项停止出站，并从仍允许数据重新投影。密码、Key、Cookie、认证资产和学校原始响应始终排除。
- 操作许可保留现有 22 类、固定工具及账号/reset 作用域。应用内“日常本地操作”授权包须单独 opt-in，精确包含 17 类：个人日程、任务、时间块创建/更新/状态（9）；出勤、听课、备注、可见性（4）；关系保存/删除（2）；撤销（1）；偏好（1）。个人记录删除与 JW/Young 刷新在包外。旧单类别许可继续有效，不加 TTL、不静默扩大、不自动转包。
- 无执行许可仍能准备具体展示卡；应用执行端依据真实目标、方案及全部许可类别决定提交或等待当前卡。仅建议硬模式允许查询、建议和准备展示卡，但必须阻止本地提交和学校来源刷新。当前唯一卡的明确自然语言确认由应用绑定并分派，模型不自行批准或记住权限；无卡短答仅续接语义，改条件使旧确认失效。
- schema 14→15 采用增量迁移并保留 schema 14 的业务、历史、设置、现有许可和凭据。输入上下文预算为约 16000 token 估算值，输出 2048；循环上限为 16 次模型请求、48 次工具调用、300 秒主动时间。预算不代表模型服务能力或费用承诺。
- 学校业务仍只读；学校挑战与额外授权由用户完成。设计批准不替用户在应用启用私人读取或日常操作包。

## 实现

Sol / max 负责 C0/C3/C4 契约、生命周期、事务、集成和根验收；Luna / max 在固定且互不重叠的范围承接上下文/工具与 Widget 适配、C3/多轮合成反例；Astra 按需只读复核。所有子代理未自行运行 SDK、真实学校、真实模型或提交，根串行执行检查；没有将子代理声明当通过。

| 落实位置 | 结果 |
|---|---|
| C3 schema 15、`agent_context_store.dart` / `agent_chat_store.dart` | 增量保存安全配对交互、应用选择、私人依赖、读取/预算策略和目标别名；原用户消息仍来自正式历史。14→15 不重写旧业务/密文/许可；旧工具原始结果未留存时不补造。每轮协议副本最多 2 MiB、总副本 8 MiB，淘汰可重建副本而不删除可见聊天 |
| C4 `agent_context.dart` | 按原角色/时间装配安全人类/助手/完整工具回合、部分安全回复、选择和回执；历史 call ID 重映射以免与新调用撞号。私人读取撤销后保守排除受影响完整派生回合/摘要，保留允许的人类输入和基础资料 |
| `AgentTargetAliasPort` 和读/写适配 | 日程/任务跨轮定位时取得当前版本；原日期范围改变或目标删除则失效，无关 revision 不清空会话。公开结果的历史交付守卫只豁免通常 catalog revision/读取期限，仍验实际 issued 对象、owner/reset、知识 epoch 和来源世代；当前读取与 cursor 仍使用完整守卫 |
| C4 工具与循环 | 19 个工具稳定可见，去掉问句词面注册、强制首读和中文/英文硬失败。多项只读可同批；修改/学校交互独立调用，多项本地变化合并为一个方案。同批混入交互调用返回可修正拒绝且零执行。每方案 20 变化不再误作整轮总数；16 次模型/48 次工具、重复无进展及参数纠错仍有界 |
| `AgentUsePolicyPort`、既有许可与 C5 | 私人内容与 17 类日常本地操作分别 opt-in；旧单项许可保留。仅建议在 C3/C2 最终执行端阻止本地写/来源刷新，仍可展示建议。当前卡文字确认与按钮共用原决定入口；否定、改条件、停止、撤销、维护和迟到决定不能越权。卡等待期间保留停止按钮 |
| `agent_context_budget.dart`、网关与 compact | 估算 16000 输入/2048 输出，75% 软阈值摘要；整组裁剪，不截断工具配对；手动/自动摘要超时排空后保留旧快照并受控回退。服务明确 `contextLimit` 时只在未产生回复/完成结果前做一次容量回退；未核验容量仍未知，固定网关/不跟携 Key 重定向保留 |
| C3 实际 action/receipt 恢复 | 真实已签发 LocalPlan 在批准前绑定规范参数 SHA256，原提交行与实际业务回执共同证明。相同调用在连续终答失败后只返回历史计数，不新增 action/receipt；查询独立于 500 消息和 8 MiB 副本。旧未分类回执为 unknown；`new_operation=true` 表达用户明确的另一个新操作，同样走当前许可/事务，同一运行实际提交后不可借此重放 |
| 固定安全诊断 | 新增上下文装配/摘要/裁剪、预算、实际工具清单和策略模式计数；日志不记录问句/回复、工具参数、private 值、目标或 receipt ID、Key、账号或原响应 |

### 可选真实模型合成验核

Agent 使用权限内折叠的“合成模型核验”仅由用户主动打开并点击开始；入口打开不启动模型。8 个代表场景及两个关键场景各另重复 3 次，共 14 个、最多 96 个实际模型请求；显示 actual usage，缺失或失败的 usage 保持未知，可随时停止/排空。工具只接独立内存合成库、固定假来源和拒绝联网的公开端口，真实配置端只提供已同意模型的安全 Key 租约。正式业务、历史、学校和浏览器资产不进入工具端。取消、配置变更、维护及退出均收口自己的资源。

已用合成 gateway 验证场景驱动、真实 C3 目标状态、延迟批准续答、停止重启、窗口关闭及安全摘要，不将这些脚本成绩当真实模型效果。根没有启动真实模型验核，也没有消耗该入口的真实模型请求；语义完成、误追问和自然回复仍待用户确认。

## 失败、修复与复核

早期根全套出现过 **1203 通过/1 平台跳过/6 失败**。旧 compact fixture 没有建立真实配对协议却要求保留它、容量测试忽略不可裁固定定义及 Iterable JSON 类型、旧 schema 期望值均按新契约修正；其中等待批准/学校阶段缺少停止按钮是实现缺陷，已修复，不把它归作旧测试问题。复跑全套曾达 1211 通过/1 跳过，之后又补实际回执恢复反例，最终结果见下表。

Windows Agent 前三次均为 **4 通过/1 失败**：设置按钮现先打开使用权限，而旧原生 fixture 直接找完整模型设置字段；另一旧断言要求普通聊天没有业务工具。修订 fixture 通过使用权限中的完整设置入口并验证 19 工具，保持配置保存/重启/秘密不回填等原断言，不修改产品以迎合旧入口。

Astra 复核暴露连续两次终答失败会丢失防重复依据。初步扫描近期未完成回合仍受消息窗口/副本淘汰影响，且会混淆新建同名记录；根改为上述 C3 独立 action/receipt 查找和新操作标志。合成测试明确删除原协议副本、超过 500 条消息仍可恢复，连续两次失败后第三轮不重复，完整结束或明确另建新操作可创建第二份；伪 ticket、跨对话和清业务 receipt 后的查询分别拒绝/无结果。后续只读复核未发现新的确定缺口。

同规范参数的恢复证明不等于模型正确判断同义需求或“另一个新操作”。来源/目标的硬边界、授权合法与模型在许可内选错目标分别评价；不因 C3/哈希正确而宣称语义绝对安全。

## 真人边界

本次新切工程检查不能覆盖原截图的真实失败。集中体验只需要三个短流程：原出勤需求自然续接到实际完成/当前卡；跨轮“第二个”/改条件；已有许可及一次无许可的当前卡文字确认。私人内容和日常授权包仍须用户分别在应用启用，不因为本对话批准而自动打开。

真实模型续接、出勤、图片/规划/来源交互和回复质量继续待验；可选合成模型核验尚未由用户运行。语音“I.”/noSpeech 未由 M5.9 修改或关闭，真实识别仍是单独待处理项。M5 与完整 V 项尚未关闭。设计批准、实际机械通过和真人通过分别保留。
